# 경매 배당

경매 낙찰대금을 정해진 순서로 나누었을 때 각 채권자가 받을 돈을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| price | 낙찰대금은 얼마인가요? | 원 |  |
| costs | 낙찰대금에서 먼저 돌려줄 경매 집행비용은 얼마인가요? | 원 |  |
| region | 경매 주택은 어느 지역에 있나요? 소액임차인 보호 한도를 나누는 지역입니다. | 서울 (seoul) / 과밀억제권역·세종·용인·화성·김포 (metro-over) / 광역시·안산·광주·파주·이천·평택 (metro-city) / 그 밖의 지역 (other) |  |
| tenant | 확정일자를 받은 임차인의 보증금은 얼마인가요? 임차인이 없으면 0원입니다. | 원 |  |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe baedang
node ../../scripts/calculator.cjs questions baedang <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate baedang <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 이 결과는 임차인 1명과 근저당 3개를 가정한 단순 배당 시나리오입니다. 실제 배당순위와 낙찰자의 인수 의무를 확정하지 않습니다. 체납세금은 임차보증금보다 먼저 배당하는 구조입니다. 임차인 확정일자와 세금의 법정기일에 따른 예외는 별도로 확인해야 합니다. 소액임차인 한도는 엔진의 지역별 표를 사용합니다. 최초 담보권 설정일에 따른 과거 한도와 배당요구 요건은 반영하지 않습니다. 권리관계를 모르면 필수 답을 추측하지 않습니다. 매각물건명세서·등기부·채권신고 자료를 확인한 뒤 계산합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
