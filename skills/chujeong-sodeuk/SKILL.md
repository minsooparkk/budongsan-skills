# 추정·인정소득

보험료나 카드 사용액으로 소득을 역산하고 입력한 인정 비율과 상한을 적용합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| method | 어떤 자료로 소득을 추정하나요? | 직장 건강보험료의 본인 부담액 (health) / 직장 국민연금의 본인 부담액 (pension) / 1년 신용카드 사용액 (card) |  |
| cardSpend | 1년 동안 사용한 신용카드 금액은 얼마인가요? | 원 | 조건: {"key":"method","value":"card"} |
| healthMonthly | 한 달 건강보험료의 본인 부담액은 얼마인가요? 장기요양보험료는 제외합니다. | 원 | 조건: {"key":"method","value":"health"} |
| pensionMonthly | 한 달 국민연금의 본인 부담액은 얼마인가요? | 원 | 조건: {"key":"method","value":"pension"} |
| healthRate | 해당 연도의 직장 건강보험료 중 본인 부담 요율은 몇 %인가요? 0보다 큰 값이 필요합니다. | 소수 비율 | 조건: {"key":"method","value":"health"} |
| pensionRate | 해당 연도의 직장 국민연금 중 본인 부담 요율은 몇 %인가요? 0보다 큰 값이 필요합니다. | 소수 비율 | 조건: {"key":"method","value":"pension"} |
| recognition | 은행이 역산 소득에서 인정하는 비율은 몇 %인가요? | 소수 비율 |  |
| capAmount | 은행이 추정소득으로 인정하는 연 소득의 상한은 얼마인가요? | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe chujeong-sodeuk
node ../../scripts/calculator.cjs questions chujeong-sodeuk <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate chujeong-sodeuk <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 선택한 방식의 자료만 질문합니다. 건강보험료·국민연금·카드 사용액 중 쓰지 않는 값은 계산에서 제외합니다. 보험료 방식은 직장가입자의 본인 부담액을 역산합니다. 지역가입자 보험료나 사업주 부담액에 이 산식을 그대로 적용하지 않습니다. 카드 방식은 사용액에 입력한 인정 비율을 곱하는 단순 시나리오입니다. 은행의 실제 카드 환산 공식이나 승인 소득을 재현한다고 답하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
