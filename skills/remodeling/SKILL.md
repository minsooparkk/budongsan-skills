# 리모델링 수익

리모델링 비용에 비해 월세 증가와 예상 매각가격 상승으로 얼마나 남는지 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| cost | 리모델링에 드는 전체 비용은 얼마인가요? | 원 |  |
| rentIncrease | 리모델링 후 월세가 매달 얼마나 더 늘 것으로 보나요? 늘지 않으면 0원입니다. | 원 |  |
| years | 리모델링 효과를 몇 년간 계산할까요? | 년 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| valueIncrease | 리모델링 덕분에 매각가격이 얼마나 더 오를 것으로 보나요? | 리모델링으로 인한 매각가격 상승은 반영하지 않았습니다. (입력값 0) |
| rate | 리모델링 자금의 연 이자율 또는 자금비용률은 얼마인가요? 5%는 0.05입니다. | 대출이자와 자기자금의 기회비용은 제외했습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe remodeling
node ../../scripts/calculator.cjs questions remodeling <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate remodeling <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 월세 증가와 매각가격 상승은 사용자의 예상입니다. 실제 임대료 인상 가능 여부나 수익을 보장하지 않습니다. 공사 중 공실·추가 유지비·매각세금은 이 산식에 직접 반영하지 않습니다. 입력한 비용 외의 부담을 함께 검토합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
