# 명도비용

임차인이 집을 비우는 절차에 드는 소송·집행·보관 비용과 못 받는 월세를 합산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| area | 짐을 반출할 공간의 전용면적은 몇 ㎡인가요? | ㎡ |  |
| laborPerPyeong | 견적에서 정한 평당 집행 노무비는 얼마인가요? | 원/평 |  |
| bailiffFee | 예상 집행관 수수료와 여비는 얼마인가요? | 원 |  |
| transport | 사다리차와 운반에 드는 예상 비용은 얼마인가요? 필요 없으면 0원입니다. | 원 |  |
| storageMonthly | 짐을 보관하는 한 달 창고 비용은 얼마인가요? 필요 없으면 0원입니다. | 원 |  |
| storageMonths | 짐을 보관할 예상 기간은 몇 개월인가요? 보관하지 않으면 0입니다. | 개월 |  |
| litigation | 인지·송달료와 변호사 보수 등 예상 소송비용은 얼마인가요? | 원 |  |
| monthly | 집을 돌려받으면 매달 받을 수 있는 월세는 얼마인가요? | 원 | 제외 조건: {"key":"delayMonths","value":0} |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| delayMonths | 집을 돌려받지 못해 월세를 받지 못할 기간을 몇 개월로 예상하나요? | 명도 지연으로 못 받는 월세는 제외하고 직접 비용만 계산했습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe myeongdo
node ../../scripts/calculator.cjs questions myeongdo <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate myeongdo <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 비용은 사용자가 입력한 견적·예상 기간을 합산한 시나리오입니다. 전국 공통 표준 보수나 확정 견적이라고 소개하지 않습니다. 못 받는 월세는 기회비용으로 구분합니다. 실제로 지급하는 소송·집행·보관 비용과 따로 보여줍니다. 진행 절차는 별도로 확인합니다. 이 계산은 명도 권리, 판결 가능성이나 강제집행을 시작할 수 있는지 판단하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
