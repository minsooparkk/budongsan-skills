# 누진세율 속산표

공제를 마친 과세표준에 선택한 누진세율표를 적용해 기본 세액을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| taxBase | 공제를 마친 과세표준은 얼마인가요? 세율을 곱하는 기준 금액이며 집값·매출·총급여와 다릅니다. | 원 |  |
| table | 어떤 세율표를 적용할까요? 적용 세목과 분류를 확인한 표를 선택합니다. | 소득세: 종합소득·양도소득의 기본세율 (income) / 상속세·증여세 (estate) / 법인세 (corp) / 법인지방소득세 (corp-local) / 주택 종합부동산세: 2주택 이하 (cpt2) / 주택 종합부동산세: 3주택 이상 (cpt3) / 주택 재산세: 일반 (prop-house) / 주택 재산세: 1세대 1주택·공시가격 9억원 이하 특례 (prop-house-1) / 토지 재산세: 종합합산 (prop-land-g) / 토지 재산세: 별도합산 (prop-land-s) |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe nujin
node ../../scripts/calculator.cjs questions nujin <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate nujin <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 이 결과는 세율표만 적용한 기본 세액입니다. 지방세·할증·세액공제·이미 낸 세금 등은 자동으로 더하거나 빼지 않습니다. 과세표준을 모르면 해당 세금의 전용 계산기에서 먼저 구합니다. 재산 총액을 과세표준으로 임의 대입하지 않습니다. 세율표의 적용 연도와 구분은 공식 자료로 확인합니다. 표 이름만으로 해당 연도 세법이나 특례 충족을 보장하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
