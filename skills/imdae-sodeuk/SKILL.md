# 주택임대소득세

과세 대상 월세와 간주임대료로 분리과세 세금과 종합과세 증가분을 비교합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| rent | 이번 연도 과세 대상 주택에서 받은 월세 수입 합계는 얼마인가요? 비과세 주택의 월세는 제외합니다. | 원 |  |
| deemed | 이번 연도 과세 대상 보증금의 간주임대료는 얼마인가요? 대상이 아님을 확인했다면 0원입니다. | 원 |  |
| otherIncome | 주택임대 외 종합소득금액은 얼마인가요? 총급여가 아니라 근로소득공제·사업 경비 등을 뺀 소득금액입니다. | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| registered | 등록임대주택의 경비율·공제 우대 요건을 모두 확인했나요? 단순히 임대사업자등록만 했다는 뜻은 아닙니다. | 등록임대주택의 추가 경비율·공제 우대는 적용하지 않았습니다. (입력값 false) |
| actualExpenses | 종합과세 비교에 사용할 장부상 실제 임대 필요경비는 얼마인가요? | 종합과세 비교는 실제 장부 경비 대신 엔진의 가정 경비율을 적용했습니다. 적법한 추계 경비율을 판정한 값이 아닙니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe imdae-sodeuk
node ../../scripts/calculator.cjs questions imdae-sodeuk <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate imdae-sodeuk <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 월세의 과세 여부를 먼저 확인합니다. 주택 수·국내외 소재지·고가주택 여부를 엔진이 받지 않으므로 비과세 월세를 넣어 세금이 있는 것처럼 답하지 않습니다. 종합과세 결과는 거친 비교값입니다. 다른 소득금액을 그대로 세율표에 넣고 인적공제·소득공제·세액공제 등을 제외하므로 실제 신고세액이나 최적 신고방식을 확정하지 않습니다. 실제 필요경비 0원은 별도로 확인합니다. 이 엔진의 0은 실제 경비가 없다는 뜻이 아니라 가정 경비율을 사용하라는 뜻입니다. 등록임대주택 우대는 등록·임대료 증액 제한 등 요건별로 확인합니다. 건강보험료 변동과 의무 위반 추징은 이 계산에 포함하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
