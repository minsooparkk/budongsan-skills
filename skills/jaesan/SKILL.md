# 재산세

부동산을 보유하면서 내는 재산세와 함께 붙는 세금을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| kind | 어떤 부동산의 재산세를 계산하나요? 토지 구분을 모르면 과세내역서부터 확인합니다. | 주택 (house) / 상가·오피스텔·공장 등 건축물 (building) / 나대지 등 종합합산 토지 (land-general) / 상가 부속토지 등 별도합산 토지 (land-separate) |  |
| price | 올해 공시가격 또는 시가표준액은 얼마인가요? 거래가격이 아니라 재산세 과세내역의 금액입니다. | 원 |  |
| oneHouse | 과세기준일인 6월 1일에 이 세대는 재산세 특례 대상인 1세대 1주택인가요? 주택이 아니면 아니오입니다. |  |  |
| urban | 해당 부동산에 재산세 도시지역분이 부과되나요? 주소 또는 이전 과세내역으로 확인합니다. |  |  |
| prevPrice | 직전 연도 공시가격은 얼마인가요? 주택이 아니거나 비교할 전년도 가격이 없는 경우에는 0원이며, 모르면 확인 후 알려주세요. | 원 |  |
| taxYear | 재산세를 계산할 해는 몇 년인가요? | 년 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| buildingValue | 주택의 건물 부분 시가표준액은 얼마인가요? 주택 외 부동산이면 0원입니다. | 주택 건물 부분의 시가표준액을 입력하지 않아 주택 소방분 지역자원시설세를 제외했습니다. 표시 합계가 고지서 전체 금액과 다를 수 있습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**

- 계산할 연도와 6월 1일의 소유·세대 주택 수를 확인합니다.
- 주택 특례에서 제외되거나 별도 판단이 필요한 상속주택·분양권·입주권·오피스텔을 확인합니다.
- 도시지역분 적용과 위험 건물 중과·조례별 세율·감면 여부를 확인합니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jaesan
node ../../scripts/calculator.cjs questions jaesan <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jaesan <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 납세자는 6월 1일 소유자를 기준으로 봅니다. 올해 중간에 사고팔았더라도 매매일별로 단순 안분하지 않습니다. 공시가격과 거래가격은 다릅니다. 시가나 희망 매매가를 공시가격 대신 쓰지 않습니다. 주택 건물 부분의 시가표준액을 생략하면 소방분 세금이 빠진 합계입니다. 누락 여부를 결과 첫 부분에 표시합니다. 특수 재산과 지역별 차이는 별도 확인이 필요합니다. 화재위험 건물 중과, 조례 세율, 개별 감면, 토지의 정확한 과세 구분을 자동 판정하지 않습니다. 2026년 재산세 비율을 사용하는 원본입니다. 다른 연도는 해당 연도 법령을 확인한 뒤 계산합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
