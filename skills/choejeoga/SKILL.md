# 경매 최저가 · 입찰보증금

경매가 유찰될 때 최저매각가격과 필요한 입찰보증금이 얼마나 줄어드는지 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| appraisal | 경매의 최초 감정가는 얼마인가요? | 원 |  |
| failures | 지금까지 몇 번 유찰되었나요? 첫 매각기일이면 0회입니다. | 회 |  |
| reduction | 법원이 정한 유찰 때마다의 가격 인하율은 얼마인가요? 예: 20%는 0.2입니다. | 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| depositRate | 매각공고에서 정한 입찰보증금 비율은 얼마인가요? 예: 10%는 0.1입니다. | 입찰보증금은 일반 매각을 가정해 최저매각가격의 10%로 계산했습니다. (입력값 0.1) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe choejeoga
node ../../scripts/calculator.cjs questions choejeoga <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate choejeoga <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 실제 입찰에는 매각공고의 최저매각가격과 보증금액을 사용합니다. 재매각 등은 보증금 비율이 달라질 수 있습니다. 가격 인하율은 법원과 사건마다 다릅니다. 20%나 30%를 확인 없이 선택하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
