# 지역자원시설세(소방분)

건물 재산세와 함께 부과되는 소방분 지역자원시설세를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| buildingValue | 건물분 시가표준액은 얼마인가요? 토지가격을 제외한 금액입니다. | 원 |  |
| kind | 세금 계산상 건물 종류는 무엇인가요? | 주택 (house) / 상가 등 일반 건축물 (building) |  |
| oneHouse | 주택의 1세대 1주택 적용 요건을 충족하나요? |  | 조건: {"key":"kind","value":"house"} |
| riskMultiple | 화재위험 건축물에 적용되는 배율은 몇 배인가요? 일반 1배, 중과 대상은 2배 또는 3배입니다. | 배 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jiyeok
node ../../scripts/calculator.cjs questions jiyeok <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jiyeok <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 배율은 건물 용도와 층수 등 법정 구분을 확인해 입력합니다. 모르면 일반 건물로 임의 분류하지 않습니다. 이 결과는 소방분 세액입니다. 재산세·도시지역분·지방교육세를 합친 고지서 전체 금액과 다릅니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
