# 건물 잔존가치

오래된 건물의 가치가 새 건물 대비 얼마나 남는지 입력한 감가 조건으로 추정합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| newCost | 같은 건물을 지금 새로 짓는 데 드는 비용은 얼마인가요? | 원 |  |
| age | 준공 후 얼마나 지났나요? | 년 |  |
| life | 가치가 줄어드는 기간을 총 몇 년으로 볼까요? 건물 구조와 평가 목적에 맞는 기간입니다. | 년 |  |
| salvage | 그 기간이 끝나도 남는 가치의 비율은 얼마로 볼까요? 10%는 0.1입니다. | 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| method | 가치가 줄어드는 방식을 고를까요? | 매년 같은 금액이 줄어드는 정액법을 적용했습니다. (입력값 "straight") |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe janjon
node ../../scripts/calculator.cjs questions janjon <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate janjon <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 이 결과는 기간과 감가 방식에 따른 단순 추정입니다. 실제 수선 상태나 세법상 감가상각액을 확정하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
