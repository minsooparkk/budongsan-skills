# 간주임대료

보증금의 일부를 임대수입으로 보는 금액을 계산해 주택임대소득 계산에 연결합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| houses | 해당 연도 규정상 소형주택을 제외하고 부부 합산으로 세는 임대 주택은 몇 채인가요? | 채 |  |
| highValueHouses | 두 채 중 기준시가가 각각 12억원을 넘는 주택은 몇 채인가요? | 채 | 조건: {"key":"houses","value":2} |
| deposits | 계산 대상 주택에서 받은 보증금 합계는 얼마인가요? 제외되는 소형주택의 보증금도 뺍니다. | 원 |  |
| rate | 계산할 귀속연도에 적용하는 간주임대료의 법정 정기예금이자율은 몇 %인가요? | 소수 비율 |  |
| days | 계산 대상 보증금을 받은 임대 기간은 해당 연도에 며칠인가요? | 일 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| interestIncome | 장부 신고에서 공제할 임대사업 관련 이자·배당 수입은 얼마인가요? | 임대사업의 이자·배당 수입 공제는 적용하지 않았습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe ganju
node ../../scripts/calculator.cjs questions ganju <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate ganju <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 간주임대료는 세금 자체가 아닙니다. 계산한 금액을 과세 대상 월세 수입에 더한 뒤 주택임대소득세를 계산합니다. 주택 수·고가주택 기준·소형주택 제외의 적용 연도를 먼저 확인합니다. 이 엔진의 고정 요건이 맞지 않는 연도에는 현행법 계산이라고 답하지 않습니다. 계산은 보증금 합계가 같은 기간 유지된 경우의 단순 산식입니다. 주택마다 임대 기간이 다르거나 보증금이 변하면 일수별 적수·3억원 공제 배분을 별도 확인합니다. 주택 수는 부부 합산하되 소득 귀속은 소유자별로 확인합니다. 부부 보증금 전체를 한 사람의 수입으로 합치지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
