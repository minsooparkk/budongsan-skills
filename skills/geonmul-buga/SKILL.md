# 건물 부가가치세

토지와 건물을 함께 거래할 때 과세 대상 건물에 붙는 부가가치세를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| price | 부가가치세를 제외한 토지와 건물의 총 거래금액은 얼마인가요? | 원 |  |
| landStd | 토지의 기준시가는 얼마인가요? 건물과 가격을 나누는 기준입니다. | 원 |  |
| buildingStd | 건물의 기준시가는 얼마인가요? | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| contractBuilding | 계약서에 따로 적은 건물 공급가액은 얼마인가요? 부가가치세를 제외한 금액입니다. | 계약서의 건물 구분금액 대신 토지·건물 기준시가 비율로 나눴습니다. (입력값 0) |
| buyerBusiness | 매수인이 매입세액 공제 요건을 확인한 과세사업용 거래인가요? | 매수인의 매입세액 공제·환급은 적용하지 않는 전제로 설명합니다. (입력값 false) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe geonmul-buga
node ../../scripts/calculator.cjs questions geonmul-buga <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate geonmul-buga <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 이 도구는 건물 공급이 부가가치세 과세 대상인 경우에만 씁니다. 국민주택 등 면세 거래나 사업의 포괄양수도 여부는 먼저 확인합니다. 사업자등록만으로 부가가치세 환급이 확정되지 않습니다. 과세사업 사용, 세금계산서, 공제 제외 사유 등을 따로 확인합니다. 기준시가 비율을 적용하는 단순 안분입니다. 감정평가액 우선 적용이나 계약금액 인정의 예외는 별도로 검토합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
