# 종합소득세

여러 소득을 합산한 뒤 공제와 이미 낸 세금을 반영해 종합소득세를 추정합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| hasEarned | 근로소득이 있나요? 급여를 받고 일한 소득을 말합니다. |  |  |
| earned | 근로소득금액은 얼마인가요? 총급여가 아니라 원천징수영수증에서 근로소득공제를 뺀 금액입니다. | 원 | 조건: {"key":"hasEarned","value":true} |
| business | 사업소득금액은 얼마인가요? 매출에서 필요경비를 뺀 금액이며, 없으면 0원입니다. | 원 |  |
| rental | 합산할 임대소득금액은 얼마인가요? 임대수입에서 필요경비를 뺀 금액이며, 없으면 0원입니다. | 원 |  |
| other | 그 밖에 종합과세로 합산할 소득금액은 얼마인가요? 없으면 0원입니다. | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| dependents | 본인을 포함해 기본공제를 받을 수 있는 사람은 몇 명인가요? 소득·나이 등 요건을 확인한 인원입니다. | 기본공제는 본인 1명분만 적용했습니다. (입력값 1) |
| deductions | 기본공제 외에 확인한 소득공제 합계는 얼마인가요? 연금보험료 공제 등입니다. | 본인 기본공제 외의 추가 소득공제를 제외했습니다. (입력값 0) |
| credits | 적용할 세액공제·감면의 합계는 얼마인가요? | 별도 세액공제·감면 대신 엔진의 표준세액공제 가정을 적용했습니다. 근로소득이 있으면 13만원, 없으면 7만원입니다. (입력값 0) |
| prepaid | 미리 낸 소득세와 지방소득세 합계는 얼마인가요? 원천징수·중간예납 등이며, 합계 세액에서 뺍니다. | 원천징수·중간예납 등 이미 낸 세금을 차감하지 않았습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jonghap
node ../../scripts/calculator.cjs questions jonghap <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jonghap <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 총수입이나 매출을 그대로 입력하면 세금이 과대계산될 수 있습니다. 각 소득은 필요한 비용·근로소득공제를 뺀 소득금액으로 넣습니다. 이 도구는 기본 합산 구조의 추정입니다. 결손금·금융소득 비교과세·분리과세·공제 한도 등 모든 신고 규정을 구현하지 않습니다. 표준세액공제의 실제 적용 요건은 별도로 확인합니다. 선택 공제나 이미 낸 세금을 생략한 결과를 최종 납부세액으로 단정하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
