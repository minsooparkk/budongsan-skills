# 임대소득 대비 이자(RTI)

임대수입이 대출이자의 몇 배인지와 이자 부담으로 역산한 대출액을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| rent | 은행이 인정하는 1년 임대소득은 얼마인가요? 월세와 은행이 인정하는 보증금 환산 수입을 합칩니다. | 원 |  |
| amount | 새 대출 원금은 얼마인가요? | 원 |  |
| rate | 새 대출의 약정 연 금리는 얼마인가요? 0보다 큰 금리가 필요합니다. | 소수 비율 |  |
| existingInterest | 기존 담보대출에서 1년 동안 내는 이자는 얼마인가요? 없으면 0원입니다. | 원 |  |
| isHousing | 주택을 임대하는 대출인가요? 상가·사무실 임대라면 아니요입니다. |  |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe rti
node ../../scripts/calculator.cjs questions rti <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate rti <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 결과는 주택 1.25배·그 밖의 부동산 1.5배를 적용한 시나리오입니다. 현재 은행의 기준과 인정 임대소득을 확인해야 합니다. 대출 승인은 추가 심사가 필요합니다. RTI 계산을 통과했다는 이유만으로 실제 대출이 가능하다고 답하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
