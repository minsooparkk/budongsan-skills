# 양도세 간편 시나리오

2년 이상 보유한 주택의 매매차익에 기준 산식을 적용해 세금 규모를 살펴봅니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| single | 같은 세대가 양도하는 집 한 채만 가지고 있나요? 세대원이 가진 집·분양권·입주권·주거용 오피스텔도 알려주세요. |  |  |
| houses | 양도 시점에 같은 세대가 가진 주택은 몇 채인가요? 분양권·입주권 등 포함 여부도 확인합니다. | 채 |  |
| regulated | 양도일 현재 이 주택은 조정대상지역에 있나요? 주소와 양도일로 확인합니다. |  |  |
| salePrice | 주택을 팔거나 팔 것으로 가정한 금액은 얼마인가요? | 원 |  |
| buyPrice | 이 주택을 실제로 산 금액은 얼마인가요? 증여·상속 등으로 취득했다면 별도 계산 범위를 확인합니다. | 원 |  |
| holdYears | 2026년 기준 시점까지 온전히 채운 보유기간은 몇 년인가요? 취득일과 양도 기준일로 확인하며 2년 미만은 지원하지 않습니다. | 년 |  |
| liveYears | 같은 기준 시점까지 실제로 거주한 기간은 몇 년인가요? 보유기간을 넘길 수 없습니다. | 년 |  |
| resident | 양도 기준일에 이 집에 실제로 거주하고 있나요? 이 2026년 계산에서는 미래 거주기간을 늘리지 않습니다. |  |  |
| saleYear | 기준 계산에서 주택을 파는 해는 몇 년인가요? 이 간편 산식의 출발 연도는 2026년입니다. | 년 |  |
| propertyKind | 파는 재산은 무엇인가요? | 주택 (house) / 토지·상가·분양권 등 그 밖의 재산 (other) |  |
| specialCase | 다음 중 하나라도 있나요? 같은 해 다른 부동산 매각, 올해 양도소득 기본공제 사용, 미등기, 상속·증여 취득, 기존 집을 남겨둔 일시적 두 주택, 실제 취득가격을 모르는 경우입니다. |  |  |
| regulatedAtAcquisition | 이 집을 샀을 때 조정대상지역이었나요? 당시 주소와 취득일을 확인해서 답을 정합니다. |  |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| expense | 양도세에서 인정되는 취득·매각 비용과 자본적 지출은 얼마인가요? | 인정 비용을 0원으로 계산했습니다. 취득세·중개보수·인정 수리비 증빙을 추가하면 세금이 줄 수 있습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**

- 주택을 일반 매매로 취득해 등기를 마쳤는지 확인합니다. 토지·주택 외 건물·권리·미등기·증여·상속·환산취득가액·이월과세는 이 주택 기준 시나리오에서 처리하지 않습니다.
- 실제 취득일과 2026년 양도 기준일을 받아 만 2년 이상 보유를 확인합니다. 단기보유 세율은 구현되지 않았습니다.
- 세대가 가진 모든 주택·입주권·분양권, 취득 당시 조정대상지역 여부, 실제 거주 시작·종료일을 확인합니다. single은 비과세 요건을 확인한 경우에만 참입니다.
- 같은 해 다른 양도와 기본공제 사용액을 확인합니다. 연간 합산·손익통산·이미 쓴 기본공제는 이 엔진에 입력할 수 없어 해당하면 별도 계산합니다.
- 다주택 중과의 한시 배제·완화와 제외 주택은 양도일별로 확인합니다. 시행 또는 개정 여부가 미확인인 숫자를 실제 납부세액으로 안내하지 않습니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe yangdo
node ../../scripts/calculator.cjs questions yangdo <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate yangdo <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 이 계산은 주택의 제한된 기준 시나리오입니다. 원래 웹 양도세 계산기의 서버 기능 전체를 포함하지 않습니다. 단기 양도와 세부 비과세 판정은 지원하지 않습니다. 2년 이상 보유라는 사실만으로 비과세라고 안내하지 않습니다. 계산 연도는 2026년으로 고정합니다. 보유·거주 기간은 같은 기준 시점으로 입력하며 매각일별 적용 규정은 별도 확인합니다. 개편안 숫자는 사용하지 않습니다. 원본의 current 산식도 자동으로 최신 검증된 세법이라는 뜻은 아닙니다. 비과세·중과의 정확한 사실관계가 확인되지 않으면 가정 결과만 제시합니다. 실제 납부 예상세액이나 신고 가능한 계산이라고 표현하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
