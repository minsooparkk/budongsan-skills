# 지적측량수수료

토지 측량의 기본단가·면적·필지 수로 측량비를 거칠게 추정합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| kind | 어떤 측량이 필요한가요? | 경계 확인·담장 설치: 경계복원 (boundary) / 땅을 여러 필지로 나누기: 분할 (division) / 건물의 현재 위치 확인: 지적현황 (status) / 임야대장에서 토지대장으로 전환: 등록전환 (conversion) / 미등록 토지를 처음 등록: 신규등록 (registration) |  |
| area | 측량할 면적은 몇 ㎡인가요? | ㎡ |  |
| parcels | 측량할 필지는 몇 개인가요? 필지는 지번으로 구분되는 토지 단위입니다. | 필지 |  |
| baseFee | 해당 지역과 측량 종류에 맞는 기본단가는 얼마인가요? LX 고시나 견적에서 확인합니다. | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| extraParcelRatio | 추가 필지 1개마다 기본단가의 몇 배를 더할까요? | 추가 필지는 1개마다 기본단가의 50%를 더하는 가정으로 계산했습니다. (입력값 0.5) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jijeok
node ../../scripts/calculator.cjs questions jijeok <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jijeok <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 이 계산은 공식 수수료표 전체를 구현하지 않은 근사식입니다. 1,000㎡ 초과 시 1,000㎡마다 기본단가의 15%를 더합니다. 실제 신청 비용은 LX 지적측량바로처리센터 견적으로 확인합니다. 지역별·종류별 공식 단가를 예제 금액으로 대체하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
