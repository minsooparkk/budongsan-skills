# 중개보수(복비)

매매나 임대차 거래에서 한쪽 당사자가 부담할 중개보수의 상한과 부가가치세를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| kind | 어떤 부동산의 거래인가요? | 주택과 그 부속토지 (house) / 전용 85㎡ 이하이며 부엌·화장실·목욕시설을 갖춘 오피스텔 (officetel-home) / 상가·토지·위 요건을 충족하지 않는 오피스텔 등 (other) |  |
| deal | 사고파는 거래인가요, 빌리는 거래인가요? | 매매·교환 (sale) / 전세·월세 임대차 (lease) |  |
| price | 매매라면 거래금액, 임대차라면 보증금은 얼마인가요? | 원 |  |
| monthly | 한 달 월세는 얼마인가요? 전세라면 0원입니다. | 원 | 조건: {"key":"deal","value":"lease"} |
| vat | 중개보수에 부가가치세 10%를 별도로 붙이는 거래인가요? 중개사의 과세유형과 견적을 확인합니다. |  |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| agreedRate | 중개사와 법정 상한보다 낮은 보수율을 합의했나요? 합의했다면 그 비율을 답합니다. | 별도 합의 요율 없이 법정 상한 요율을 적용했습니다. 상한은 반드시 내야 할 정가가 아닙니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe junggae
node ../../scripts/calculator.cjs questions junggae <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate junggae <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 보수는 거래 당사자 한쪽의 부담액입니다. 매수인과 매도인의 보수를 합친 금액이 아닙니다. 주택 요율은 지역 조례까지 확인합니다. 엔진은 고정 요율표를 쓰므로 지역별 더 낮은 상한이 있으면 그대로 확정하지 않습니다. 부가가치세 처리는 견적과 사업자 과세유형에 맞춰 확인합니다. 10% 별도 여부가 아니면 엔진의 0원 표시가 모든 거래의 부가가치세 면제를 뜻하지 않습니다. 무료 중개 합의는 별도 확인합니다. 이 엔진의 합의 요율 0은 보수 0원이 아니라 상한 적용을 뜻합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
