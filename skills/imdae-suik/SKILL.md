# 임대수익률

집이나 상가를 빌려주어 남는 돈과 투자금 대비 수익률을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| price | 부동산 매입가는 얼마인가요? | 원 |  |
| deposit | 임차인에게 받을 보증금은 얼마인가요? 없으면 0원입니다. | 원 |  |
| monthly | 매달 받을 월세는 얼마인가요? | 원 |  |
| loan | 매입에 사용하는 대출 원금은 얼마인가요? 없으면 0원입니다. | 원 |  |
| loanRate | 대출의 약정 연 금리는 얼마인가요? | 소수 비율 | 제외 조건: {"key":"loan","value":0} |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| expenses | 1년 재산세·수선비·관리비·보험료 등 운영 경비는 얼마인가요? | 연 운영 경비는 제외했습니다. 실제 경비가 있으면 순수익과 현금흐름이 줄어듭니다. (입력값 0) |
| vacancy | 1년 중 세입자가 없어 월세를 못 받는 비율을 얼마나 가정할까요? | 공실 없이 1년 내내 월세를 받는 상황을 가정했습니다. (입력값 0) |
| acquisitionCost | 취득세·중개보수·등기비용 등 매입 부대비용은 얼마인가요? | 매입 부대비용은 제외했습니다. 실제 비용을 넣으면 투자금과 수익률이 달라집니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe imdae-suik
node ../../scripts/calculator.cjs questions imdae-suik <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate imdae-suik <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 수익률은 세전 비교값입니다. 대출 원금 상환, 임대소득세와 매각 시세차익은 반영하지 않습니다. 자기자본은 매입가와 취득비용을 더한 뒤 보증금·대출을 뺀 금액입니다. 0 이하라면 자기자본수익률이 의미 없다고 설명하고 자금 구성을 확인합니다. 선택 비용을 생략한 결과는 비용 제외 시나리오입니다. 이를 실제 순수익 예상치라고 소개하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
