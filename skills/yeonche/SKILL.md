# 연체 임대료 이자

밀린 월세 원금과 지연 일수에 따른 이자를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| monthly | 한 달 월세는 얼마인가요? | 원 |  |
| months | 밀린 월세의 합계가 몇 개월치인가요? 일부만 밀렸다면 0.5개월처럼 답할 수 있습니다. | 개월 |  |
| days | 각 월세가 늦어진 일수의 평균은 며칠인가요? 납부기한과 계산 기준일을 알려 주면 평균을 구할 수 있습니다. | 일 |  |
| annualRate | 이 계약에 적용할 연체이자율은 연 몇 %인가요? 약정 유무와 계약 성격을 확인한 값을 넣습니다. | 소수 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe yeonche
node ../../scripts/calculator.cjs questions yeonche <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate yeonche <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 지연일수는 금액으로 가중한 평균을 사용합니다. 회차별 연체액이 다르면 각 금액과 일수를 받아 가중평균을 구합니다. 계약 해지는 별도 검토가 필요합니다. 엔진의 2기 기준은 주택·민법상 임대차의 단순 표시이며 상가임대차 등 다른 계약에 그대로 적용하지 않습니다. 법정이율이나 약정이율의 효력은 계약 성격에 따라 확인합니다. 모든 임대료 연체에 연 5%나 연 20% 상한이 일률 적용된다고 답하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
