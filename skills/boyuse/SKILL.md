# 보유세 비교

집 한 채를 가진 세대의 명의·거주 조건에 따라 보유세가 어떻게 달라지는지 비교합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| caseKey | 어떤 소유·거주 조건을 계산하나요? 공동명의 개별납부는 부부가 절반씩 소유하는 시나리오입니다. | 단독명의이며 거주함 (sole-live) / 단독명의이며 거주하지 않음 (sole-away) / 부부 공동명의로 거주하며 각자 납부함 (joint-live) / 부부 공동명의로 거주하지 않으며 각자 납부함 (joint-away) / 부부 공동명의로 거주하며 1주택자 특례를 신청함 (joint-live-special) / 부부 공동명의로 거주하지 않으며 1주택자 특례를 신청함 (joint-away-special) |  |
| price | 주택 전체 공시가격은 얼마인가요? 공동명의도 본인 지분이 아니라 집 전체 가격을 알려주세요. | 원 |  |
| age | 세액공제를 적용받을 납세자의 만 나이는 몇 살인가요? 부부 특례이면 지정한 납세의무자 기준입니다. | 세 |  |
| holdYears | 해당 기준일까지 이 주택을 보유한 기간은 몇 년인가요? | 년 |  |
| liveYears | 해당 기준일까지 이 주택에 실제 거주한 기간은 몇 년인가요? | 년 |  |
| specialCase | 다음 중 하나라도 있나요? 세대 안에 집이 두 채 이상, 법인 명의, 부부가 아닌 공동소유, 부부 공동명의이지만 절반씩이 아닌 지분입니다. |  |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| regime | 어떤 산식으로 비교할까요? 개편안은 시행 확정 여부와 별개인 가정입니다. | 개편안을 선택하지 않아 원본의 기준 산식으로 계산했습니다. 자동으로 최신 확정 세법을 검증했다는 뜻은 아닙니다. (입력값 "current") |

**적용 범위에 필요한 사실도 확인한다.**

- 세대가 가진 주택이 한 채인지, 소유자가 개인인지, 공동소유이면 부부인지와 실제 지분을 확인합니다.
- 부부 공동명의 특례이면 신청 여부와 납세의무자를 확인합니다. 미신청자는 신청했다고 가정하지 않습니다.
- 실제 납부세액을 묻는 경우 기준일 법령·공시가격·재산세 부과내역·전년도 부담상한을 별도로 확인합니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe boyuse
node ../../scripts/calculator.cjs questions boyuse <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate boyuse <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 결과는 1세대 1주택 비교 시나리오입니다. 다주택·법인·부부 외 공동소유를 계산하는 일반 종합부동산세 계산기가 아닙니다. 공동명의 개별납부는 지분 50%씩으로 계산합니다. 지분이 다르면 해당 결과를 실제 세액으로 안내하지 않습니다. 보유세 합계에는 원본이 산출한 종합부동산세·농어촌특별세·재산세·도시지역분·지방교육세가 들어갑니다. 소방분 지역자원시설세는 포함하지 않습니다. 재산세는 단순화한 기준입니다. 공정시장가액비율 45%, 표준세율과 도시지역분을 고정 사용하며 1주택 저가구간 특례·전년도 부담상한·지역별 차이를 모두 반영하지 않습니다. 현재 산식과 개편안은 구분해서 표시합니다. 2027년·2028년 숫자는 원본이 담은 정책 가정이며 법률 시행을 확정하지 않습니다. 공동명의 특례는 신청 요건을 확인해야 합니다. 나이와 보유기간만으로 자동 적용하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
