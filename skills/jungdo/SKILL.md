# 중도상환수수료

약정 만기보다 일찍 갚는 대출금에 대해 기간 비례 수수료를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| amount | 이번에 미리 갚을 대출 원금은 얼마인가요? | 원 |  |
| feeRate | 대출 약정서의 중도상환수수료율은 몇 %인가요? | 소수 비율 |  |
| elapsedMonths | 대출을 받은 뒤 몇 개월이 지났나요? | 개월 |  |
| feeMonths | 약정서에 정한 수수료 부과 기간은 몇 개월인가요? 면제 상품이라면 0입니다. | 개월 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jungdo
node ../../scripts/calculator.cjs questions jungdo <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jungdo <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 계산은 남은 부과 기간에 비례해 수수료가 줄어드는 약정에 사용합니다. 모든 대출의 수수료 방식을 재현하지 않습니다. 면제 한도는 별도로 반영합니다. 일정 금액을 수수료 없이 갚는 약정이 있다면 면제 금액을 확인한 뒤 과금 대상 금액만 넣습니다. 개월 기준 계산은 일수 기준 은행 청구액과 차이가 날 수 있습니다. 약정서의 요율과 기준일을 확인합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
