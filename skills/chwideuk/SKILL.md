# 취득세

부동산을 살 때·받을 때 내는 취득세와 함께 붙는 세금을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| cause | 어떤 방법으로 부동산을 취득하나요? | 돈을 주고 매매 (purchase) / 대가 없이 증여받음 (gift) / 사망한 가족에게 상속받음 (inherit) / 건물을 새로 지음 (original) |  |
| kind | 어떤 부동산을 취득하나요? | 주택 (house) / 상가·오피스텔 등 주택 외 건물이나 일반 토지 (building) / 농지 (land-farm) |  |
| price | 취득세 계산에 쓸 취득가액은 얼마인가요? 매매는 거래금액, 증여·상속은 확인한 세법상 평가액을 알려주세요. | 원 |  |
| area | 주택의 전용면적은 몇 제곱미터인가요? 주택이 아니면 0으로 표시합니다. | ㎡ |  |
| regulated | 취득일 현재 이 부동산은 조정대상지역에 있나요? 주소와 취득일로 확인하며 모르는 경우 임의로 정하지 않습니다. |  |  |
| houses | 취득 후 같은 세대가 가진 주택은 모두 몇 채인가요? 이번 주택과 주택 수에 포함되는 분양권·입주권·오피스텔도 확인합니다. | 채 |  |
| corporate | 취득하는 사람은 법인인가요? 회사 명의이면 예, 개인 명의이면 아니오입니다. |  |  |
| temporaryTwo | 새 집을 사면서 기존 집도 잠시 갖게 되나요? 해당하면 두 집의 취득일과 기존 집을 팔 예정인 날짜를 알려주세요. 그 밖에는 아니오입니다. |  |  |
| soleHeirHouse | 상속받은 뒤 같은 가구가 가진 집이 이 상속주택 한 채뿐인가요? 상속이 아니면 아니오입니다. |  |  |
| specialCase | 다음 중 하나라도 있나요? 주택을 증여받음, 읍·면의 전용 85㎡ 초과 100㎡ 이하 주택, 별장·고급주택, 이 계산에 없는 별도 세금 감면입니다. |  |  |
| firstHomeNeverOwned | 본인과 배우자 모두 지금까지 집을 소유한 적이 없나요? 공유지분·상속주택도 포함해 알려주세요. |  | 적용 조건: {"key":"firstHome","value":true} |
| firstHomeWillLive | 이번에 산 집에서 본인이 실제로 살 예정인가요? |  | 적용 조건: {"key":"firstHome","value":true} |
| acquisitionYear | 부동산을 취득하는 해는 몇 년인가요? | 년 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| firstHome | 생애최초 주택구입 감면을 검토할까요? 적용하려면 본인·배우자의 과거 주택 소유와 거주 요건을 확인합니다. | 생애최초 주택구입 감면을 적용하지 않았습니다. 감면 대상이면 세금이 줄 수 있습니다. (입력값 false) |
| firstHomeSmall | 생애최초 감면 중 소형주택·인구감소지역 등에 적용되는 300만원 한도 요건도 확인됐나요? | 생애최초 감면을 적용하는 경우에도 300만원 추가 한도는 적용하지 않았습니다. (입력값 false) |

**적용 범위에 필요한 사실도 확인한다.**

- 부동산의 주소와 취득일을 확인하고 취득일에 적용되는 조정대상지역 지정 여부를 확인합니다.
- 가족이 보유한 다른 주택·분양권·입주권·주거용 오피스텔과 주택 수 제외 특례를 확인합니다.
- 주택 증여라면 증여자와 받는 사람의 관계, 증여자의 세대 주택 수, 시가표준액과 취득세 과세표준을 각각 확인합니다. 원본으로 처리할 수 없는 중과 예외는 지원 범위 밖으로 안내합니다.
- 농어촌특별세의 주택 면적 예외와 별도 감면·중과가 있으면 표준 계산을 확정 결과로 안내하지 않습니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe chwideuk
node ../../scripts/calculator.cjs questions chwideuk <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate chwideuk <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 취득세 합계에는 취득세 본세·지방교육세·농어촌특별세가 들어갑니다. 중개보수와 등기비용은 별도입니다. 주택 수와 조정대상지역은 필수 사실입니다. 모르겠다는 답을 1채나 비규제지역으로 바꾸지 않습니다. 주택 외 부동산에서는 사용되지 않는 주택 관련 값만 질문 없이 해당 없음으로 정리할 수 있습니다. 원래 엔진의 주택 수 범위 때문에 비주택의 houses는 계산상 1을 씁니다. 증여 취득세의 중과 판정은 추가 확인이 필요합니다. 원본 엔진은 증여 중과 기준의 평가액 구분과 1세대 1주택자의 배우자·직계가족 증여 예외를 별도 입력받지 않으므로 해당 가능성이 있으면 확정 세액을 내지 않습니다. 전용 85㎡ 경계는 모든 지역에 그대로 적용할 수 없습니다. 국민주택규모가 100㎡인 읍·면 예외 등은 별도 확인합니다. 일시적 두 주택은 날짜 확인이 필요합니다. 단순히 나중에 팔겠다는 답만으로 temporaryTwo를 참으로 정하지 않으며 기준일의 처분기한을 확인합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
