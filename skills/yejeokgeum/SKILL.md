# 예금·적금 이자

예금이나 적금의 세전 이자, 이자에서 뺄 세금과 만기 수령액을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| kind | 목돈을 한 번 맡기는 예금인가요, 매달 넣는 적금인가요? | 목돈을 한 번 맡기는 예금 (deposit) / 같은 금액을 매달 넣는 적금 (installment) |  |
| amount | 처음에 맡길 예금 원금은 얼마인가요? | 원 | 조건: {"key":"kind","value":"deposit"} |
| monthly | 적금에 매달 넣을 금액은 얼마인가요? | 원 | 조건: {"key":"kind","value":"installment"} |
| rate | 상품의 약정 연 금리는 얼마인가요? | 소수 비율 |  |
| months | 돈을 넣어 둘 기간은 몇 개월인가요? | 개월 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| compound | 이자가 다음 달 원금에 붙는 월복리 상품인가요? | 이자에 다시 이자를 붙이지 않는 단리로 계산했습니다. (입력값 false) |
| taxRate | 이자에서 공제하는 세금 비율은 몇 %인가요? 비과세 요건을 확인했다면 0입니다. | 일반적인 이자 원천징수율 15.4%를 적용했습니다. 세금우대·비과세 및 종합과세 추가 세금은 반영하지 않았습니다. (입력값 0.154) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe yejeokgeum
node ../../scripts/calculator.cjs questions yejeokgeum <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate yejeokgeum <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 적금은 매달 초에 같은 금액을 넣는 것으로 계산합니다. 납입일·우대금리 달성 여부·은행의 일수와 세금 절사 기준에 따라 실제 수령액과 차이가 납니다. 세후 이자는 입력한 원천징수율 기준입니다. 금융소득 종합과세로 나중에 추가되는 세금까지 계산한 값은 아닙니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
