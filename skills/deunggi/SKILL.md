# 등기비용

매매로 부동산을 산 뒤 소유권을 옮길 때 드는 취득세와 등기 비용을 합산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| kind | 매매로 사는 부동산은 무엇인가요? | 주택 (house) / 오피스텔 (officetel) / 상가·건물 (building) / 일반 토지(농지 제외) (land) |  |
| price | 매매계약서의 거래금액은 얼마인가요? | 원 |  |
| standardValue | 채권 매입의 기준이 되는 시가표준액은 얼마인가요? 주택 공시가격이나 지자체 확인 자료를 사용합니다. | 원 |  |
| metro | 부동산이 특별시 또는 광역시에 있나요? 수도권 여부와는 다른 구분입니다. |  |  |
| area | 주택의 전용면적은 몇 ㎡인가요? | ㎡ | 조건: {"key":"kind","value":"house"} |
| regulated | 취득일에 이 주택이 조정대상지역에 있나요? |  | 조건: {"key":"kind","value":"house"} |
| houses | 이번에 사는 집까지 포함해 세대가 보유하는 주택은 몇 채인가요? 분양권 등 포함 여부도 확인합니다. | 채 | 조건: {"key":"kind","value":"house"} |
| corporate | 개인이 아니라 법인이 사는 부동산인가요? |  |  |
| legalFee | 법무사와 협의한 총 보수는 얼마인가요? 견적에서 별도 비용과 중복되지 않는 금액을 넣습니다. | 원 | 제외 조건: {"key":"selfRegistration","value":true} |
| discountRate | 채권을 사서 바로 되팔 때 적용하는 할인율은 몇 %인가요? 10%라면 10을 답합니다. | % |  |
| mortgageMax | 새로 설정할 근저당의 채권최고액은 얼마인가요? 근저당 설정이 없으면 0원입니다. | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| firstHome | 생애최초 주택 취득세 감면 요건을 확인했나요? | 생애최초 주택 취득세 감면은 적용하지 않았습니다. (입력값 false) |
| temporaryTwo | 주택 취득세 중과에서 제외되는 일시적 2주택 요건을 확인했나요? | 일시적 2주택에 따른 중과 제외는 적용하지 않았습니다. (입력값 false) |
| selfRegistration | 법무사를 쓰지 않고 직접 등기하나요? | 법무사에게 등기를 맡기는 경우로 계산했습니다. 보수는 별도로 확인한 금액을 사용합니다. (입력값 false) |
| eForm | 전자표준양식인 e-Form으로 소유권이전등기를 신청하나요? | 서면 등기신청 수수료를 적용했습니다. e-Form이나 완전 전자신청과는 수수료가 다릅니다. (입력값 false) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe deunggi
node ../../scripts/calculator.cjs questions deunggi <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate deunggi <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 계산은 매매 취득 전용입니다. 증여·상속·농지 취득과 특수 감면은 해당 계산기로 별도 확인합니다. 시가표준액은 실제 확인한 값을 사용합니다. 엔진에 0을 넣으면 거래가의 70%로 추정하므로 미확인 값을 0으로 보내지 않습니다. 채권 할인율은 등록 당일 고시값을 확인합니다. 이 필드만 백분율 숫자를 사용하므로 10%는 10이고 0.1이 아닙니다. 주택 면적과 주택 수는 실제 법적 판정에 맞게 확인합니다. 면적 85㎡ 기준만 사용하는 엔진이므로 지역별 국민주택규모 예외 등 특수한 상황을 확정 계산으로 답하지 않습니다. 합계에는 취득세 관련 세금·인지세·채권 할인비용·등기 수수료·입력한 법무사 보수와 근저당 관련 비용이 들어갑니다. 중개보수나 누락된 실비는 추가해야 합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
