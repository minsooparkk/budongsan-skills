# 전세보증보험

전세보증금과 선순위 채권으로 담보 한도를 점검하고 입력한 요율로 보증료를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| deposit | 보장받으려는 전세보증금은 얼마인가요? | 원 |  |
| homePrice | 보증기관 기준으로 인정되는 주택가격은 얼마인가요? 매매 호가와 다를 수 있습니다. | 원 |  |
| seniorDebt | 먼저 보호되는 근저당 채권최고액과 앞선 임차보증금은 모두 얼마인가요? 등기부와 계약관계를 확인하고, 없으면 0원입니다. | 원 |  |
| apartment | 주택 유형이 아파트인가요? |  |  |
| metro | 집이 서울·경기·인천 중 한 곳에 있나요? |  |  |
| feeRate | 보증기관이 적용하는 연 보증료율은 몇 %인가요? | 소수 비율 |  |
| years | 보증을 받을 기간은 몇 년인가요? | 년 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe bojeung-boheom
node ../../scripts/calculator.cjs questions bojeung-boheom <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate bojeung-boheom <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 가입 여부는 보증기관이 최종 결정합니다. 엔진의 가능 표시는 담보인정비율 90%와 수도권 7억원·그 밖 5억원 한도만 통과했다는 뜻입니다. 현재 상품 기준을 확인합니다. 신청 시기·주택 유형·임차권·선순위 비율 등의 추가 요건과 보증료 할증·할인은 자동 판정하지 않습니다. 주택 유형은 요율을 확인하는 데 필요합니다. 엔진은 아파트 여부로 요율을 자동 변경하지 않으므로 사용자가 확인한 요율을 넣습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
