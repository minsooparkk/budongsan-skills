# 전월세 전환·보증금 조정

보증금과 월세를 서로 바꿀 때 달라지는 보증금과 월세를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| deposit | 현재 보증금은 얼마인가요? | 원 |  |
| monthly | 현재 월세는 얼마인가요? 전세라면 0원입니다. | 원 |  |
| direction | 어느 방향으로 바꾸나요? | 보증금을 줄이고 월세 늘리기 (toMonthly) / 월세를 줄이고 보증금 늘리기 (toDeposit) |  |
| amount | 바꿀 금액은 얼마인가요? 보증금을 줄이면 줄일 보증금, 월세를 줄이면 줄일 한 달 월세를 답합니다. | 원 |  |
| baseRate | 계약 시점의 한국은행 기준금리는 몇 %인가요? | 소수 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| agreedRate | 따로 합의한 연 전환율은 몇 %인가요? | 합의 전환율을 따로 적용하지 않고 기준금리로 계산한 법정 상한을 사용했습니다. 월세를 보증금으로 바꿀 때는 같은 비율로 역산한 참고값입니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jeonwolse
node ../../scripts/calculator.cjs questions jeonwolse <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jeonwolse <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 법정 상한의 적용 여부는 계약 상황을 먼저 확인합니다. 이 계산은 주택의 보증금을 월세로 전환하는 산식을 사용합니다. 월세를 보증금으로 바꾸는 역방향 결과는 자유롭게 합의할 금액의 참고값입니다. 엔진은 역방향에도 같은 상한 내 비율을 쓰므로 그 비율이 법적 의무라고 답하지 않습니다. 전환 금액은 현재 보증금 또는 현재 월세를 넘을 수 없습니다. 초과 입력을 엔진이 자동으로 줄인 값으로 대신 확정하지 말고 사용자에게 확인합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
