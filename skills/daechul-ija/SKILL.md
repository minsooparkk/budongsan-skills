# 대출 이자·상환표

매달 갚을 돈과 만기까지의 총이자를 상환 방식에 따라 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| amount | 빌릴 대출 원금은 얼마인가요? | 원 |  |
| rate | 약정 연 금리는 얼마인가요? | 소수 비율 |  |
| years | 대출 만기는 몇 년인가요? 개월로 약정했다면 개월 수를 12로 나눕니다. | 년 |  |
| repay | 대출 원금을 어떤 방식으로 갚나요? | 매달 원금과 이자의 합계를 같게 갚기(원리금균등) (annuity) / 매달 원금을 같게 갚고 남은 원금의 이자 내기(원금균등) (principal) / 매달 이자를 내다가 마지막에 원금 전부 갚기(만기일시) (bullet) |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| graceYears | 처음에 원금을 갚지 않고 이자만 내는 기간은 몇 년인가요? 개월 수를 알면 12로 나눕니다. | 거치기간 없이 첫 달부터 약정 방식으로 갚는 것으로 계산했습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe daechul-ija
node ../../scripts/calculator.cjs questions daechul-ija <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate daechul-ija <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 계산 결과는 입력한 금리·한도를 적용한 비교값입니다. 금융기관의 실제 대출 승인이나 적용 규제를 확정하지 않습니다. 대출 기간은 정수 개월이어야 합니다. 금리·상환 조건이 바뀌면 다시 계산합니다. 금리는 만기까지 변하지 않는 것으로 계산합니다. 실제 이자 납부일, 일수 계산과 은행의 원 단위 처리 때문에 청구액과 차이가 날 수 있습니다. 거치기간은 만기 이내여야 합니다. 원리금균등·원금균등은 거치가 끝난 뒤 적어도 1개월이 남아야 합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
