# 집값 대비 대출(LTV)

집값에서 기존 채권과 방공제를 뺀 담보 기준 대출액을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| price | 은행이 담보가치로 인정하는 집값은 얼마인가요? | 원 |  |
| ltv | 은행이 이 대출에 적용하는 집값 대비 대출 비율(LTV)은 몇 %인가요? | 소수 비율 |  |
| senior | 이 대출보다 먼저 보호되는 기존 대출·임차보증금 합계는 얼마인가요? 없음을 확인했다면 0원입니다. | 원 |  |
| region | 방공제를 적용할 부동산은 어느 지역에 있나요? | 서울 (seoul) / 과밀억제권역·세종·용인·화성·김포 (metro-over) / 광역시·안산·경기 광주·파주·이천·평택 (metro-city) / 그 밖의 지역 (other) |  |
| rooms | 은행이 방공제에 적용하는 방 수는 몇 실인가요? 집의 실제 방 개수와 다를 수 있습니다. | 실 |  |
| cap | 은행이 적용하는 대출 금액의 별도 상한은 얼마인가요? 상한이 없음을 확인했다면 0원입니다. | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| mci | 방공제를 면제하는 MCI 보험이나 MCG 보증에 가입하나요? | MCI·MCG에 가입하지 않는 것으로 보고 방공제를 차감했습니다. (입력값 false) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe ltv
node ../../scripts/calculator.cjs questions ltv <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate ltv <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 결과는 담보 기준 비교값입니다. 소득 심사와 DSR, 금융기관의 상품 조건에 따라 실제 한도는 줄어듭니다. 방공제는 소액임차인 보호를 위해 은행이 담보가치에서 빼는 금액입니다. 주소와 담보 설정 시점에 맞는 지역 분류·공제액을 확인합니다. 별도 상한의 0원은 상한이 없다는 뜻입니다. 상한을 모른다는 뜻으로 입력하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
