# 소득 대비 빚 비율(DTI)

주택담보대출 상환액과 다른 대출의 이자가 연소득에서 차지하는 비율을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| income | 증빙할 수 있는 1년 소득은 얼마인가요? | 원 |  |
| amount | 새 주택담보대출 원금은 얼마인가요? | 원 |  |
| rate | 새 주택담보대출의 약정 연 금리는 얼마인가요? | 소수 비율 |  |
| years | 대출 만기는 몇 년인가요? 개월로 약정했다면 개월 수를 12로 나눕니다. | 년 |  |
| existingMortgage | 기존 주택담보대출의 1년 원금·이자 상환액은 얼마인가요? 없으면 0원입니다. | 원 |  |
| otherInterest | 그 밖의 대출에서 1년 동안 내는 이자는 얼마인가요? 없으면 0원입니다. | 원 |  |
| limit | 은행이 적용하는 DTI 한도는 몇 %인가요? | 소수 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe dti
node ../../scripts/calculator.cjs questions dti <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate dti <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 계산 결과는 입력한 금리·한도를 적용한 비교값입니다. 금융기관의 실제 대출 승인이나 적용 규제를 확정하지 않습니다. 대출 기간은 정수 개월이어야 합니다. 금리·상환 조건이 바뀌면 다시 계산합니다. 신규 주택담보대출은 원리금균등 방식으로 계산합니다. 다른 상환 방식이나 은행의 세부 환산 규칙은 반영하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
