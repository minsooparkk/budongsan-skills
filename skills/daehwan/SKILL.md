# 대출 대환 이자 비교

기존 대출을 새 대출로 바꿀 때 이자와 비용이 얼마나 달라지는지 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| balance | 현재 갚지 않은 대출 원금은 얼마인가요? | 원 |  |
| currentRate | 현재 대출의 약정 연 금리는 얼마인가요? | 소수 비율 |  |
| remainingYears | 현재 대출의 남은 기간은 몇 년인가요? 개월로 약정했다면 개월 수를 12로 나눕니다. | 년 |  |
| newRate | 새 대출의 약정 연 금리는 얼마인가요? | 소수 비율 |  |
| newYears | 새 대출의 만기는 몇 년인가요? 개월로 약정했다면 개월 수를 12로 나눕니다. | 년 |  |
| prepayFee | 기존 대출을 지금 갚으면 내는 중도상환수수료는 얼마인가요? 면제를 확인했다면 0원입니다. | 원 |  |
| repay | 대출 원금을 어떤 방식으로 갚나요? | 매달 원금과 이자의 합계를 같게 갚기(원리금균등) (annuity) / 매달 원금을 같게 갚고 남은 원금의 이자 내기(원금균등) (principal) / 매달 이자를 내다가 마지막에 원금 전부 갚기(만기일시) (bullet) |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| costs | 새 대출 때문에 드는 설정비·인지세·감정비 등 추가 비용은 얼마인가요? | 새 대출의 설정비·인지세·감정비 등 추가 비용은 제외했습니다. 실제 부담액이 있으면 절감액이 줄어듭니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe daehwan
node ../../scripts/calculator.cjs questions daehwan <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate daehwan <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 계산 결과는 입력한 금리·한도를 적용한 비교값입니다. 금융기관의 실제 대출 승인이나 적용 규제를 확정하지 않습니다. 대출 기간은 정수 개월이어야 합니다. 금리·상환 조건이 바뀌면 다시 계산합니다. 두 대출은 같은 상환 방식으로 비교합니다. 상환 방식이 서로 다르면 대출 이자 계산기를 각각 실행해 비교합니다. 비용 회수 기간은 첫 달 상환액 차이로 나눈 단순값입니다. 원금균등의 월별 변동과 장기적인 현금 가치는 반영하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
