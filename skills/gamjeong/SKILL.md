# 감정평가 (원가·비교·수익 8방식)

부동산 가격이나 연 임대료를 선택한 평가 방식으로 추정합니다. 선택한 방식에 필요한 정보만 묻습니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| method | 어떤 근거로 부동산 가격이나 연 임대료를 추정할까요? | 새로 짓는 비용과 토지가격으로 평가: 원가법 (cost) / 비슷한 부동산의 거래가격으로 평가: 거래사례비교법 (sales) / 표준지 공시지가로 토지를 평가: 공시지가기준법 (land) / 연간 순수익으로 가격을 평가: 수익환원법 (income) / 여러 해의 미래 수익을 오늘 가치로 평가: DCF (dcf) / 비슷한 임대사례로 연 임대료를 평가: 임대사례비교법 (rent-sales) / 부동산 가치와 목표수익으로 연 임대료를 평가: 적산법 (rent-cost) / 사업 이익 중 부동산 몫으로 연 임대료를 평가: 수익분석법 (rent-income) |  |
| landValue | 토지만의 평가금액은 얼마인가요? | 원 | 조건: {"key":"method","value":"cost"} |
| newCost | 같은 건물을 지금 새로 짓는 데 드는 비용은 얼마인가요? | 원 | 조건: {"key":"method","value":"cost"} |
| residualRate | 건물의 가치가 새 건물 대비 얼마나 남았다고 보나요? 예: 70%는 0.7입니다. | 비율 | 조건: {"key":"method","value":"cost"} |
| caseValue | 비교할 사례의 금액은 얼마인가요? 거래사례는 매매가격, 임대사례는 1년 임대료입니다. | 원 | 조건: {"key":"method","values":["sales","rent-sales"]} |
| officialPrice | 비교 표준지의 ㎡당 공시지가는 얼마인가요? | 원/㎡ | 조건: {"key":"method","value":"land"} |
| area | 평가할 토지 면적은 몇 ㎡인가요? | ㎡ | 조건: {"key":"method","value":"land"} |
| noi | 1년 임대수입에서 운영비를 뺀 순수익은 얼마인가요? 대출이자와 소득세를 빼기 전 금액입니다. | 원 | 조건: {"key":"method","values":["income","dcf"]} |
| capRate | 가격으로 환산할 연 수익률은 얼마인가요? 주변 거래 수익률 등이 근거이며 5%는 0.05입니다. | 비율 | 조건: {"key":"method","value":"income"} |
| years | 미래 수익을 몇 년간 예상할까요? | 년 | 조건: {"key":"method","value":"dcf"} |
| discountRate | 미래 돈을 오늘 가치로 바꿀 연 할인율은 얼마인가요? 기대수익과 위험을 고려하며 6%는 0.06입니다. | 비율 | 조건: {"key":"method","value":"dcf"} |
| exitCap | 예상 보유기간 끝에 매도가격을 구할 연 환원율은 얼마인가요? 5%는 0.05입니다. | 비율 | 조건: {"key":"method","value":"dcf"} |
| baseValue | 임대료 계산의 바탕이 될 부동산 가치는 얼마인가요? | 원 | 조건: {"key":"method","value":"rent-cost"} |
| expectedRate | 그 부동산 가치에 대해 기대하는 연 수익률은 얼마인가요? 4%는 0.04입니다. | 비율 | 조건: {"key":"method","value":"rent-cost"} |
| businessProfit | 해당 장소에서 올리는 1년 영업이익은 얼마인가요? | 원 | 조건: {"key":"method","value":"rent-income"} |
| rentShare | 영업이익 중 부동산이 기여한 비율은 얼마라고 보나요? 30%는 0.3입니다. | 비율 | 조건: {"key":"method","value":"rent-income"} |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| timeFactor | 거래·임대 시점 차이를 몇 배로 보정할까요? 차이가 없으면 1배입니다. | 시점 보정배율은 1배로 두어 기간 중 가격 변동을 반영하지 않았습니다. (입력값 1) |
| areaFactor | 면적·규모 차이를 몇 배로 보정할까요? 차이가 없으면 1배입니다. | 면적·규모 보정배율은 1배로 두어 크기 차이를 반영하지 않았습니다. (입력값 1) |
| conditionFactor | 위치·상태 등 개별 차이를 몇 배로 보정할까요? 차이가 없으면 1배입니다. | 개별요인 보정배율은 1배로 두어 위치·상태 차이를 반영하지 않았습니다. (입력값 1) |
| otherFactor | 그 밖의 차이를 몇 배로 보정할까요? 차이가 없으면 1배입니다. | 기타 보정배율은 1배로 두어 추가 조정을 하지 않았습니다. (입력값 1) |
| timeRate | 공시기준일과 평가일의 가격 차이를 몇 배로 보정할까요? 차이가 없으면 1배입니다. | 시점수정 배율은 1배로 두어 기간 중 지가 변동을 반영하지 않았습니다. (입력값 1) |
| regionFactor | 지역 차이를 몇 배로 보정할까요? 차이가 없으면 1배입니다. | 지역 보정배율은 1배로 두어 지역 차이를 반영하지 않았습니다. (입력값 1) |
| itemFactor | 도로·모양 등 토지의 개별 차이를 몇 배로 보정할까요? 차이가 없으면 1배입니다. | 개별요인 보정배율은 1배로 두어 토지의 개별 차이를 반영하지 않았습니다. (입력값 1) |
| growth | 연간 순수익은 매년 얼마나 늘거나 줄 것으로 보나요? 2% 증가는 0.02, 2% 감소는 -0.02입니다. | 연간 순수익이 매년 같은 금액으로 유지된다고 가정했습니다. (입력값 0) |
| expenses | 임대료에 더할 1년 세금·수선비·관리비 등은 얼마인가요? | 연간 세금·수선비·관리비 등 추가 경비를 제외했습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe gamjeong
node ../../scripts/calculator.cjs questions gamjeong <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate gamjeong <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 이 결과는 입력한 가정에 따른 산식 결과입니다. 감정평가사가 작성한 평가서나 세법상 인정되는 감정가액을 대신하지 않습니다. 임대사례의 금액은 1년 기준으로 맞춥니다. 월 임대료를 답하면 12를 곱해 연 임대료로 바꾼 뒤 확인합니다. DCF는 매년 말에 수익을 받고 마지막에 매각하는 구조입니다. 마지막 다음 해 순수익을 최종환원율로 나누어 매도가격을 계산합니다. 보정배율 1은 차이를 조정하지 않는 가정입니다. 실제 두 부동산의 가치가 같다는 판단을 뜻하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
