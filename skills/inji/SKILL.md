# 인지세

부동산 매매계약서에 붙는 인지세와 매수인이 나눠 낼 몫을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| amount | 계약서에 적힌 거래금액은 얼마인가요? | 원 |  |
| isHouse | 계약서는 완성된 주택의 매매계약서인가요? 분양권·입주권 전매는 아니오로 답합니다. |  |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| buyerShare | 매수인이 부담하기로 한 비율은 얼마인가요? 절반이면 0.5입니다. | 매수인과 매도인이 인지세를 절반씩 부담한다고 가정했습니다. (입력값 0.5) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe inji
node ../../scripts/calculator.cjs questions inji <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate inji <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 절반 부담은 계산상 가정입니다. 실제 분담 약정과 법상 공동 작성자의 납부 책임은 별도로 확인합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
