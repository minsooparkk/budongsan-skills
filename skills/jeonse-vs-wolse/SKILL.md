# 전세와 월세 비교

전세대출 이자와 보증금을 다른 곳에 맡겼다면 받을 이자를 고려해 월 부담을 비교합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| jeonse | 비교할 전세보증금은 얼마인가요? | 원 |  |
| wolseDeposit | 비교할 월세집의 보증금은 얼마인가요? | 원 |  |
| monthly | 비교할 월세집의 한 달 월세는 얼마인가요? | 원 |  |
| loanShare | 전세보증금 중 대출로 마련할 비율은 몇 %인가요? 대출이 없으면 0입니다. | 소수 비율 |  |
| loanRate | 전세대출의 약정 연 금리는 얼마인가요? | 소수 비율 | 제외 조건: {"key":"loanShare","value":0} |
| depositRate | 자기 돈을 예금 등에 맡겼다면 받을 연 이자율을 얼마로 비교할까요? | 소수 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jeonse-vs-wolse
node ../../scripts/calculator.cjs questions jeonse-vs-wolse <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jeonse-vs-wolse <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 월 부담은 월세·대출이자·보증금의 기회비용을 합한 비교값입니다. 기회비용은 실제로 지출하는 돈이 아니라 포기한 이자입니다. 월세 보증금은 자기 돈으로 마련하는 것으로 계산합니다. 월세 보증금에도 대출을 쓴다면 이 비교에 그 이자가 빠진다는 점을 먼저 설명합니다. 보증보험료·이사비·세액공제·보증금 반환 위험은 별도입니다. 이 결과만으로 어느 계약이 개인에게 더 좋은지 단정하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
