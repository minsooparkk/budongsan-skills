# 증여세

가족이나 다른 사람에게 재산을 받을 때 내는 증여세를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |

**적용 범위에 필요한 사실도 확인한다.**

- 받는 사람이 한국 세법상 거주자인지, 이미 지난 신고인지와 신고기한 내 신고 여부를 확인합니다.
- 지난 10년 증여 내역과 기본공제 사용 이력, 혼인·출산 공제의 전체 사용 이력을 확인합니다.
- 세대를 건너뛴 증여이면 중간 세대의 사망 등 할증 예외와 과거 합산 여부를 확인합니다.
- 혼인·출산 공제를 선택하면 혼인신고일 또는 출생·입양일과 증여일을 직접 비교하고 동일 공제의 중복 사용을 확인합니다.
- 혼인·출산 공제를 선택하면 정확한 증여일·행사 종류·신고일 또는 출생일을 필수로 묻습니다. 신고서의 증여 연·월과 일치하는지도 확인합니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jeungyeo
node ../../scripts/calculator.cjs questions jeungyeo <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jeungyeo <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 증여세는 받는 사람이 내는 세금입니다. 부동산 취득세와 빚을 넘기는 사람의 양도소득세는 별도입니다. 과거 증여 이력은 필수입니다. 과거 증여가 없다는 답을 받았을 때만 관련 금액을 모두 0원으로 정리할 수 있습니다. 과거 증여세 공제에는 산출세액을 씁니다. 실제 납부액이나 통장 출금액을 대신 넣지 않으며, 이전 입력 방식인 priorGiftTaxPaid는 항상 0으로 유지합니다. 신고세액공제 3%는 기한 안에 적법하게 신고하는 가정입니다. 지연 신고라면 그대로 적용하지 않습니다. 한국 세법상 거주자의 일반 증여만 지원합니다. 비거주자·증여의제·가업승계 등 특례와 세대생략 증여의 과거 합산은 이 간편 계산으로 처리하지 않습니다. 재산 평가액은 확인한 금액을 사용합니다. 호가나 주변 매물을 근거 없이 신고용 평가액으로 바꾸지 않습니다. 혼인·출산 공제는 날짜와 가족관계를 확인한 뒤 적용합니다. 결혼식 날짜가 아닌 혼인신고일, 자녀의 출생일 또는 입양신고일을 사용합니다. 출생·입양 전 증여는 출산 공제에 포함하지 않습니다. 혼인은 신고일 전후 2년, 출생·입양은 해당일부터 2년 이내로 범위를 나눕니다. 혼인신고 예정일을 사용한 결과는 예정된 혼인이 이뤄지는 가정입니다. 실제로 혼인하지 않거나 기간을 넘기면 공제와 신고 내용을 다시 확인해야 합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
