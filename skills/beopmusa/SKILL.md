# 법무사 보수

부동산의 명의를 옮길 때 법무사에게 지급할 보수를 추정합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| base | 소유권을 이전할 부동산의 취득세 과세표준은 얼마인가요? 일반 매매에서는 거래금액을 확인합니다. | 원 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| mortgage | 함께 설정할 근저당의 채권최고액은 얼마인가요? | 근저당 설정 업무의 보수는 제외했습니다. (입력값 0) |
| expenses | 교통비·증명서 발급비 등 별도 실비는 얼마인가요? | 교통비·증명서 발급비 등 별도 실비는 제외했습니다. (입력값 0) |
| discount | 법무사와 협의한 할인율은 얼마인가요? 예: 10%는 0.1입니다. | 협의 할인을 적용하지 않았습니다. (입력값 0) |
| vat | 부가가치세를 포함해서 볼까요? | 보수와 입력한 실비에 부가가치세 10%를 더했습니다. (입력값 true) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe beopmusa
node ../../scripts/calculator.cjs questions beopmusa <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate beopmusa <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 취득세·인지세·채권 할인비용은 이 보수에 포함하지 않습니다. 법무사 견적서의 공과금 항목을 별도로 확인합니다. 근저당 설정 보수는 이전등기 기본보수의 70%로 가정합니다. 실제 계약 보수와 다를 수 있습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
