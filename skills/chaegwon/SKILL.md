# 국민주택채권

등기 때 국민주택채권을 사고 바로 팔면 부담할 할인비용을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| kind | 등기할 부동산의 종류는 무엇인가요? | 주택: 아파트·단독·다세대 등 (house) / 오피스텔 (officetel) / 상가·일반 건물 (building) / 토지 (land) |  |
| standardValue | 부동산의 시가표준액은 얼마인가요? 거래가격 대신 채권 매입 기준으로 안내받은 금액을 넣습니다. | 원 |  |
| metro | 부동산은 특별시 또는 광역시에 있나요? |  |  |
| discountRate | 등기 당일 은행이 안내한 채권 할인율은 몇 %인가요? 예: 10%는 10입니다. | % |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| couponRate | 채권을 보유할 경우의 연 표면금리는 몇 %인가요? 예: 1.3%는 1.3입니다. | 보유 이자는 반영하지 않도록 참고 표면금리를 0%로 두었습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe chaegwon
node ../../scripts/calculator.cjs questions chaegwon <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate chaegwon <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 할인율은 매일 바뀝니다. 당일 취급 은행의 실제 고시값을 확인해야 부담액을 계산할 수 있습니다. 보유와 즉시매도 중 어느 쪽이 유리한지는 이 할인비용만으로 판단하지 않습니다. 표면금리와 매도 가격·만기·세금을 함께 비교합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
