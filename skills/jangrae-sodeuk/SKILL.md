# 장래소득

현재 소득에 나이별 증가율을 적용해 대출 심사용 소득의 변화를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| income | 현재 1년 소득은 얼마인가요? | 원 |  |
| age | 신청자의 만 나이는 몇 세인가요? | 세 |  |
| years | 대출 만기는 몇 년인가요? 개월로 약정했다면 개월 수를 12로 나눕니다. | 년 |  |
| rate20 | 은행이 만 20~24세에게 적용하는 소득 증가율은 몇 %인가요? | 소수 비율 | 조건: {"key":"age","values":[20,21,22,23,24]} |
| rate25 | 은행이 만 25~29세에게 적용하는 소득 증가율은 몇 %인가요? | 소수 비율 | 조건: {"key":"age","values":[25,26,27,28,29]} |
| rate30 | 은행이 만 30~34세에게 적용하는 소득 증가율은 몇 %인가요? | 소수 비율 | 조건: {"key":"age","values":[30,31,32,33,34]} |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jangrae-sodeuk
node ../../scripts/calculator.cjs questions jangrae-sodeuk <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jangrae-sodeuk <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 결과는 입력한 증가율의 시나리오입니다. 예제의 증가율을 현재 은행의 적용표라고 소개하지 않습니다. 적용 대상은 별도로 확인합니다. 엔진은 만 20~34세와 만기 10년 이상만 확인하므로, 실제 분할상환 주택담보대출 요건까지 자동 판정하지 않습니다. 장래소득은 대출 심사를 위한 가정값입니다. 앞으로 실제로 받게 될 연봉을 예측한 값이 아닙니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
