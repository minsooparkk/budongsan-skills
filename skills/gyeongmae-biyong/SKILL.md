# 경매 신청 비용

채권자가 경매를 신청할 때 미리 낼 세금·송달료·감정료 등을 추정합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| claim | 경매로 받으려는 채권 청구금액은 얼마인가요? | 원 |  |
| appraisal | 경매 대상 부동산의 예상 감정가는 얼마인가요? | 원 |  |
| parties | 송달할 이해관계인은 몇 명인가요? 채권자·채무자·소유자 등 송달 대상 수입니다. | 명 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| appraisalFee | 법원이 안내한 감정료가 있으면 얼마인가요? | 감정료는 예상 감정가에 감정평가 기준 수수료의 하한 배율과 부가가치세를 적용해 추정했습니다. (입력값 0) |
| noticeFee | 별도로 안내받은 신문공고료는 얼마인가요? | 신문공고료를 제외한 비용만 계산했습니다. (입력값 0) |
| bailiffFee | 현황조사·집행관 수수료는 얼마인가요? | 현황조사·집행관 수수료를 제외한 비용만 계산했습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe gyeongmae-biyong
node ../../scripts/calculator.cjs questions gyeongmae-biyong <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate gyeongmae-biyong <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 송달료는 최소 2명에 대해 1명당 10회·회당 5,200원으로 가정합니다. 실제 법원의 예납 통지와 다를 수 있습니다. 선택 비용을 생략한 합계에는 해당 비용이 빠집니다. 신청 전에 법원 예납 통지에 적힌 항목과 금액으로 보완합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
