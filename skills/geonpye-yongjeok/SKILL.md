# 건폐율 · 용적률

땅 대비 건물 면적의 비율과 입력한 상한에 따른 최대 건축면적을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| siteArea | 대지면적은 몇 ㎡인가요? 건물이 있는 땅의 전체 면적입니다. | ㎡ |  |
| buildingArea | 건축면적은 몇 ㎡인가요? 건물을 위에서 내려다본 면적을 뜻합니다. | ㎡ |  |
| floorArea | 용적률 계산에 들어가는 지상 연면적은 몇 ㎡인가요? 각 층의 해당 면적을 합합니다. | ㎡ |  |
| maxCoverage | 해당 토지에 적용되는 건폐율 상한은 얼마인가요? 60%는 0.6입니다. | 비율 |  |
| maxFar | 해당 토지에 적용되는 용적률 상한은 얼마인가요? 200%는 2입니다. | 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe geonpye-yongjeok
node ../../scripts/calculator.cjs questions geonpye-yongjeok <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate geonpye-yongjeok <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 상한은 토지의 용도지역과 지자체 조례·특례를 확인해 입력합니다. 주소나 용도지역 없이 법정 상한을 임의로 정하지 않습니다. 건축 가능 여부는 이 비율만으로 확정되지 않습니다. 높이·도로·일조·주차 등 다른 허가 기준도 적용됩니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
