# 길이 환산

길이를 미터·피트·인치·자 등 여러 단위로 바꿉니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| value | 바꿀 길이는 얼마인가요? | 선택한 길이 단위 |  |
| unit | 입력한 길이의 단위는 무엇인가요? | 미터(m) (m) / 킬로미터(km) (km) / 센티미터(cm) (cm) / 밀리미터(mm) (mm) / 인치(in) (inch) / 피트(ft) (ft) / 야드(yd) (yd) / 마일(mi) (mile) / 자(尺) (ja) / 리(里) (ri) |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe gilyi
node ../../scripts/calculator.cjs questions gilyi <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate gilyi <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 길이와 면적은 다른 값입니다. 평과 제곱미터를 바꾸려면 면적 환산을 사용합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
