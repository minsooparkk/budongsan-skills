# 법정상속분

배우자와 자녀 등 가족이 법에 따라 나누는 기본 상속 비율을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| hasSpouse | 돌아가신 분에게 법률상 배우자가 있나요? |  |  |
| children | 상속하는 자녀는 몇 명인가요? 먼저 사망한 자녀가 있으면 그 자녀의 가족도 따로 확인합니다. | 명 |  |
| parents | 살아 있는 부모 등 가장 가까운 직계존속은 몇 명인가요? 자녀가 없을 때 상속 순위를 판단하는 데 사용합니다. | 명 |  |
| siblings | 살아 있는 형제자매는 몇 명인가요? 자녀·부모 등 직계존속·배우자가 없을 때 사용합니다. | 명 |  |
| specialCase | 다음 중 하나라도 있나요? 먼저 사망한 자녀의 가족이 대신 상속함, 상속포기, 상속권 상실, 유언·분할합의, 특정 가족의 생전 증여나 특별한 부양 기여입니다. |  |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| estate | 빚 등을 정리하고 나눌 상속재산은 얼마인가요? 금액 없이 비율만 보고 싶으면 생략할 수 있습니다. | 상속재산 금액을 입력하지 않아 나누는 비율만 계산했습니다. 0원은 실제 재산이 없다는 뜻이 아닙니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**

- 사망일과 배우자·자녀·부모의 존재를 확인하고 먼저 사망한 자녀의 배우자·자녀가 대신 상속하는지 확인합니다.
- 유언·분할 합의·상속포기·상속결격·특별수익·기여분이 있으면 법정상속분 예시와 실제 권리 판단을 구분합니다.
- 유류분을 묻는 경우 사망일에 적용되는 법률과 헌법재판소 결정 이후 개정 내용을 별도로 확인합니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe sangsok-jibun
node ../../scripts/calculator.cjs questions sangsok-jibun <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate sangsok-jibun <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 법정상속분은 기본적인 배분 비율입니다. 유효한 유언이나 상속인 전원의 분할 합의가 있으면 실제 배분은 달라질 수 있습니다. 상속세와 상속지분은 별도입니다. 이 계산기는 세금을 계산하지 않습니다. 대습상속·상속포기·상속결격·기여분·특별수익은 별도 확인이 필요합니다. 해당 사실을 자녀 수만 조정해 처리하지 않습니다. 유류분 금액은 법정상속분만으로 확정할 수 없습니다. 원본이 함께 내는 단순 비율은 기준일 법령과 생전 증여·기여분 등을 확인하기 전 반환청구액으로 안내하지 않습니다. 부모 수에는 가까운 순위를 먼저 적용합니다. 부모와 조부모를 같은 순위로 더하지 않습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
