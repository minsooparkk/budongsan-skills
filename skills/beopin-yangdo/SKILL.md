# 법인 부동산 양도

회사가 부동산을 팔아서 추가로 부담하는 법인세와 지방소득세를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| kind | 회사가 파는 부동산은 어떤 종류인가요? 사업용 토지는 실제 사용 이력을 확인합니다. | 주택·별장과 그 부수토지 (house) / 비사업용 토지 (land-nonbiz) / 조합원입주권·분양권 (right) / 상가·공장 등 사업용 건물 (building) / 사업용 토지 (land-biz) |  |
| price | 부동산을 파는 금액은 얼마인가요? | 원 |  |
| cost | 매각 시점에 장부에 남은 부동산 가액은 얼마인가요? 감가상각이 있으면 처음 산 가격과 다를 수 있습니다. | 원 |  |
| otherIncome | 이번 매각을 빼고 계산한 해당 사업연도의 법인세 과세표준은 얼마인가요? 매출이 아니라 세금 계산용 이익이며, 결손이면 별도 계산이 필요합니다. | 원 |  |
| unregistered | 회사가 소유권 등기를 하지 않은 상태로 파나요? |  |  |
| businessYearStart | 이번 매각이 속하는 사업연도는 몇 년에 시작했나요? | 년 |  |
| specialCase | 다음 중 하나라도 있나요? 이번 해 손실, 공제할 이전 연도 손실, 다른 부동산 매각 손실, 임대주택 등 별도 추가과세 제외 사유입니다. |  |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| expenses | 매각비용 등 아직 장부가액에 반영하지 않은 인정 비용은 얼마인가요? | 매각비용 등 추가 비용을 0원으로 계산했습니다. 장부가액에 이미 포함한 비용은 다시 빼지 않습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**

- 사업연도의 시작일과 끝나는 날, 이번 매각을 제외한 과세표준을 확인합니다.
- 당기·이월 결손금과 다른 토지 등 매각 손실이 있으면 원본의 비음수 증분 계산 범위를 벗어나는지 확인합니다.
- 추가과세 제외 주택·토지인지, 사업용 토지의 사용기간 요건을 충족하는지 확인합니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe beopin-yangdo
node ../../scripts/calculator.cjs questions beopin-yangdo <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate beopin-yangdo <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 계산 결과는 이번 매각으로 늘어나는 세금입니다. 회사가 1년 동안 낼 법인세 전체 금액은 아닙니다. 다른 소득은 필수입니다. 실제 매출이나 통장 잔액 대신 이번 매각을 제외한 세금 계산용 과세표준을 사용합니다. 결손이나 다른 부동산 매각 손실은 단순히 0원으로 바꾸지 않습니다. 이월결손금·소득 통산·세액공제와 추가과세 제외 사유는 별도 검토가 필요합니다. 2026년 1월 1일 이후 시작하는 사업연도의 원본 세율을 씁니다. 결산월과 사업연도 시작일을 먼저 확인합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
