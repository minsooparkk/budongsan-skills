# 경매 적정 입찰가

경매로 산 부동산의 임대수익을 기준으로 입찰가격 시나리오를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| monthly | 예상 월 임대료는 얼마인가요? | 원 |  |
| deposit | 돌려줘야 하는 임대보증금은 얼마인가요? 없으면 0원입니다. | 원 |  |
| targetYield | 실제로 넣은 돈에서 기대하는 연 순수익률은 얼마인가요? 5%는 0.05입니다. | 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| annualExpenses | 1년 운영비는 얼마인가요? 보유세·수선비·관리비 등입니다. | 연간 운영비를 제외한 수익으로 계산했습니다. (입력값 0) |
| vacancy | 월세를 못 받는 공실 비율은 얼마로 볼까요? 5%는 0.05입니다. | 공실 없이 1년 내내 월세를 받는다고 가정했습니다. (입력값 0) |
| acquisitionRate | 매수 가격 대비 취득세·중개보수 등 취득비용 비율은 얼마인가요? 5%는 0.05입니다. | 취득세·중개보수 등 가격에 비례하는 취득비용을 제외했습니다. (입력값 0) |
| extraCost | 명도·수리 등 한 번 드는 추가 비용은 얼마인가요? | 명도·수리 등 일회성 추가 비용을 제외했습니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe jeokjeong-ipchal
node ../../scripts/calculator.cjs questions jeokjeong-ipchal <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate jeokjeong-ipchal <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 이 결과는 목표 수익률을 맞추는 가격 시나리오입니다. 시장가치나 권장 매수·입찰 가격을 확정하지 않습니다. 공실과 비용을 생략하면 감당할 수 있는 가격이 높게 나옵니다. 실제 결정을 하기 전 운영비·취득세·수리비를 보완합니다. 대출이자와 매각 시 세금은 이 산식에 직접 반영하지 않습니다. 임대보증금은 수입이 아니라 나중에 돌려줄 돈입니다. 미납관리비·인수할 보증금·명도비 등 경매 특유의 부담은 권리분석 후 비용에 반영해야 합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
