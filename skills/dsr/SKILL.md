# 빚 갚을 능력 비율(DSR)

연소득에서 대출을 갚는 돈이 차지하는 비율과 입력한 한도 안의 대출액을 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| income | 증빙할 수 있는 1년 소득은 얼마인가요? | 원 |  |
| existing | 기존 대출의 DSR 계산용 연간 원금·이자 합계는 얼마인가요? 기존 대출이 없으면 0원입니다. | 원 |  |
| amount | 새로 빌리려는 대출 원금은 얼마인가요? | 원 |  |
| rate | 새 대출의 약정 연 금리는 얼마인가요? | 소수 비율 |  |
| years | 대출 만기는 몇 년인가요? 개월로 약정했다면 개월 수를 12로 나눕니다. | 년 |  |
| repay | 대출 원금을 어떤 방식으로 갚나요? | 매달 원금과 이자의 합계를 같게 갚기(원리금균등) (annuity) / 매달 원금을 같게 갚고 남은 원금의 이자 내기(원금균등) (principal) / 매달 이자를 내다가 마지막에 원금 전부 갚기(만기일시) (bullet) |  |
| stress | 은행이 한도 계산에만 더하는 스트레스 가산금리는 몇 %p인가요? 미적용을 확인했다면 0입니다. | 소수 비율 |  |
| limit | 은행이 적용하는 DSR 한도는 몇 %인가요? | 소수 비율 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |


**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe dsr
node ../../scripts/calculator.cjs questions dsr <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate dsr <답변 JSON 파일의 절대경로>
```

**이 계산기는 가정 시뮬레이션이다.** 계산 결과는 입력한 금리·한도를 적용한 비교값입니다. 금융기관의 실제 대출 승인이나 적용 규제를 확정하지 않습니다. 대출 기간은 정수 개월이어야 합니다. 금리·상환 조건이 바뀌면 다시 계산합니다. 기존 대출의 환산 방법은 상품마다 다릅니다. 통장에서 실제 빠진 금액을 DSR 환산액이라고 단정하지 않습니다. 원금균등은 초기 원금의 이자를, 만기일시는 원금을 만기로 나눈 금액과 이자를 사용한 근사 계산입니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
