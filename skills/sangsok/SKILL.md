# 상속세

사망한 가족의 재산을 물려받을 때 내는 상속세를 계산합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**적용 범위에 필요한 사실도 확인한다.**

- 돌아가신 분의 한국 세법상 거주자 여부와 신고기한 내 신고인지 확인합니다.
- 사망 전 5년 안에 상속인이 아닌 사람에게 준 증여, 상속인 아닌 사람에게 유증한 재산, 배우자에게 한 사전증여가 있으면 지원 범위를 다시 판단합니다.
- 배우자 외에 자녀·부모·대습상속인이 있는지 확인하고 부모와 공동상속하거나 대습상속하는 경우 원본 단순 가족식에 넣지 않습니다.
- 미성년자는 생년월일별 남은 연수를 확인합니다. 정확한 인적공제 구현이 없으면 별도 계산 대상으로 안내합니다.
- 동거주택 공제를 선택하면 동거·주택 보유 이력과 상속인의 요건을 확인합니다.
- 동거주택 공제를 선택하면 성년 이후 동거연수, 같은 세대 여부, 세대의 전체 주택 이력, 상속 직전 자녀의 주택 소유, 상속지분, 동거 중단 사실을 각각 묻습니다.

**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe sangsok
node ../../scripts/calculator.cjs questions sangsok <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate sangsok <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 상속세는 상속재산 전체를 기준으로 계산합니다. 상속인 한 명이 받는 금액만 전체 재산으로 넣지 않습니다. 가족 구성과 사전증여는 필수입니다. 배우자·자녀·부모의 존재나 과거 증여를 일반적인 가정으로 생략하지 않습니다. 미성년자가 있으면 정확한 공제 계산을 추가해야 합니다. 원본은 1명당 남은 기간 10년으로 단순화하므로 나이를 확인하기 전 결과를 확정 예상세액으로 안내하지 않습니다. 배우자 공제에는 추가 제한이 있습니다. 상속인 아닌 사람에게 준 유증, 배우자의 사전증여, 자녀 없이 부모와 함께 상속하는 경우는 이 엔진만으로 처리하지 않습니다. 거주자 사망의 일반 상속만 지원합니다. 비거주자·세대생략·가업·영농·단기재상속·특수 금융재산은 별도 계산이 필요합니다. 신고기한과 세율은 별도로 확인합니다. year와 month는 원본에서 기한 안내에만 쓰이며 과거 연도 세법을 자동 적용하지 않습니다. 신고세액공제 3%는 적법한 기한 내 신고 가정입니다. 신고가 늦었다면 최종 결과를 조정해야 합니다. 동거주택 공제는 동거기간·가족관계·주택 보유 이력을 답한 뒤 적용합니다. 단순히 공제를 검토하겠다는 답만으로 주택가액을 빼지 않습니다. 동거주택 공제의 지원 범위는 좁게 정했습니다. 성년 이후 10년 이상 계속 동거한 무주택 자녀가 주택 전체를 받는 일반 사례만 계산하며, 공동지분·동거 중단·일시적 두 주택은 별도 검토합니다. 공제 범위 밖이라는 안내는 공제 불가능 판정이 아닙니다. 법률상 예외가 있을 수 있으나 이 엔진은 해당 예외를 계산할 입력과 산식을 갖추지 않았습니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
