# 임대료 상승분

현재 보증금과 월세에 증액 상한을 적용하고 마지막 계약·인상 이후의 기간을 확인합니다.

**계산 결과는 실행한 코드의 출력과 공개한 전제에 근거해 설명한다.** 먼저 [공통 대화 절차](../../docs/conversation.md)를 읽고 아래 계산기 계약을 적용한다.

**필수 정보만 먼저 묻는다.** 사용자가 이미 제공한 값은 다시 묻지 않고, 해당되는 조건부 질문만 한다.

| 입력 키 | 쉽게 묻는 질문 | 단위·선택지 | 조건 |
| --- | --- | --- | --- |
| deposit | 현재 보증금은 얼마인가요? | 원 |  |
| monthly | 현재 월세는 얼마인가요? 전세라면 0원입니다. | 원 |  |
| monthsSince | 계약 체결 또는 마지막 임대료 인상 뒤 몇 개월이 지났나요? 더 최근 시점부터 셉니다. | 개월 |  |

**선택 질문은 건너뛸 수 있다.** 생략하거나 “기본값”이라고 답하면 다음 전제를 사용하고 결과에서 밝힌다.

| 입력 키 | 선택 질문 | 생략할 때 적용하는 전제 |
| --- | --- | --- |
| localCap | 지역 조례에서 정한 5%보다 낮은 증액 상한이 있나요? 있으면 그 비율을 답합니다. | 더 낮은 지역 상한은 반영하지 않고 5% 상한을 적용했습니다. 지역 조례에 더 낮은 상한이 있으면 달라집니다. (입력값 0) |

**적용 범위에 필요한 사실도 확인한다.**



**정확한 입력 형식은 실행기로 확인한다.** 아래 경로는 이 SKILL.md의 폴더를 기준으로 한다. 실제 호출 시 절대경로로 해석한다.

```text
node ../../scripts/calculator.cjs describe imdaeryo-sangseung
node ../../scripts/calculator.cjs questions imdaeryo-sangseung <답변 JSON 파일의 절대경로>
node ../../scripts/calculator.cjs calculate imdaeryo-sangseung <답변 JSON 파일의 절대경로>
```

**이 계산기는 예상 금액 계산이다.** 계약 유형을 먼저 확인합니다. 갱신요구권 행사·등록임대주택·신규 계약 여부에 따라 이 상한의 적용 여부가 달라지므로 결과만으로 인상이 적법하다고 단정하지 않습니다. 계산값은 같은 비율로 보증금과 월세를 늘리는 경우의 상한입니다. 둘을 전환하면서 비율까지 다르게 조정하는 경우에는 전월세 전환 계산을 함께 확인합니다. 1년이 지나지 않았다면 인상 가능액으로 확정하지 않습니다. 장래 시점 가정 금액과 현재 청구 가능 여부를 구분합니다.

**결과부터 설명한다.** 예상 금액 또는 비교 결론, 사용자 답변, 생략한 전제, 계산 과정, 적용 범위 순서로 쓴다. 법령·약정 확인이 남으면 예상 결과와 함께 그 사실을 짧게 표시한다.
