# 실행과 문답의 동작을 검증했습니다

**0.1.0 버전은 자동 검증 2,572개를 통과했습니다.** 2026-09-07에 58개 계산기의 최소 입력 예제와 입력·문답 계약 1,775개, 대화 회귀 검증 97개, 기존 계산 엔진 검증 700개를 실행했습니다. 같은 검증은 저장소에서 `npm test`로 실행할 수 있습니다. 별도 npm 패키지 설치는 필요하지 않습니다.

**검증은 사용자가 겪는 동작을 확인합니다.** 필수 답을 지우면 질문이 반환되고, 선택 답을 지우면 공개된 전제가 적용되는지 확인합니다. 계산 방식에 따라 필요한 질문이 달라지는 경우, 잘못된 숫자와 단위, 지원하지 않는 세금 사례, 날짜 조건, 금액·기간의 모순도 확인합니다.

**계산 불가와 의미 있는 특수 결과를 구분합니다.** 대환으로 절약되는 돈이 없거나 리모델링 후 월세가 늘지 않으면 “회수 불가”를 표시합니다. 중개보수의 별도 정액 한도가 없는 경우에도 요율 상한은 적용합니다. 등기비용에 포함된 취득세 계산이 실패하면 전체 합계를 정상 결과로 보여주지 않습니다.

**배포 파일은 원본 계산 모듈과 대조했습니다.** TypeScript 5.9.3의 엄격한 타입 검사와 재빌드 일치 검증을 통과했습니다. 실행용 JavaScript를 포함하므로 일반 사용자는 TypeScript를 설치하지 않습니다. 원본 파일의 지문은 [출처 안내](source-provenance.md)와 `engine/provenance.json`에 있습니다.

**플러그인 형식은 두 제품의 검증 도구로 확인했습니다.** Codex 플러그인 검증, Claude Code 플러그인·마켓플레이스 검증, 스킬 58개의 문서 형식 검증을 통과했습니다. Codex CLI의 개인 마켓플레이스 목록에서도 플러그인이 식별됐습니다. 사용자별 계정·정책·버전에 따른 설치 성공까지 보장하는 의미는 아닙니다.

**법령의 모든 예외를 검증한 결과는 아닙니다.** 자동 검증은 프로그램의 계산과 입력 처리를 확인하며, 과세관청이 인정하는 신고세액이나 금융회사의 심사결과를 확정하지 않습니다. 적용 연도를 바꿔도 세율이 자동으로 바뀌지 않습니다. 날짜에 민감한 계산기는 2026년 밖의 기준일을 추가 검토 대상으로 안내합니다.

**원본과 다른 입출력 처리는 실행기에 모았습니다.** 재건축의 남은 기간은 실행한 컴퓨터의 연도 대신 요청한 기준일로 계산합니다. 고정된 가정은 사용자가 임의로 바꾸지 못하게 검증하고, 비활성화된 과거 답이 새 결과에 섞이지 않게 처리합니다. 원본 수식 파일 자체는 이 처리를 위해 수정하지 않았습니다.
