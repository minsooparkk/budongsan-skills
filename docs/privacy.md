# 개인정보 안내

**이 플러그인은 계산에 필요한 조건만 사용하도록 설계했습니다.** 금액, 관계, 기간, 필요한 범위의 지역 정보만으로 계산하며, 실명이나 주민등록번호로 사용자를 확인하는 기능은 없습니다.

## 계산 프로그램은 로컬에서 실행됩니다

**플러그인에는 별도 계산 서버나 자체 이용 추적 기능이 없습니다.** 동봉된 계산 프로그램이 로컬에서 실행되며, 플러그인 자체가 입력값을 budongsanbaksa 서버나 별도 수집 서버로 보내지 않습니다.

**AI 대화는 이용 중인 서비스의 정책을 따릅니다.** Codex 또는 Claude Code에 입력한 질문과 답변은 해당 제품의 설정·계정·서비스 정책에 따라 처리됩니다. 로컬 계산이라는 설명은 AI 대화 전체가 외부로 전송되지 않는다는 뜻은 아닙니다.

**설치와 자료 확인에는 네트워크가 사용될 수 있습니다.** 플러그인을 GitHub에서 받거나 AI가 법령·공식 안내를 확인하는 과정은 계산 프로그램의 로컬 실행과 구분됩니다.

## 이름과 식별번호는 입력하지 않아도 됩니다

**다음처럼 계산에 필요한 내용만 말하세요.** 실제 사람이나 계좌를 식별하는 정보는 필요하지 않습니다.

| 필요한 내용 | 이렇게 답하세요 | 넣지 않아도 되는 내용 |
| --- | --- | --- |
| 재산을 주는 사람과 받는 사람의 관계 | “부모가 성년 자녀에게 줍니다.” | 가족의 실명, 주민등록번호 |
| 금액과 시기 | “2026년에 현금 1억원을 줍니다.” | 계좌번호, 송금 화면 |
| 부동산 조건 | “서울에 있는 전용 84㎡ 아파트입니다.” | 소유자 이름, 동·호수 |
| 대출 조건 | “대출 1억원, 연 4%, 1년입니다.” | 대출 계좌번호, 금융회사 로그인 정보 |

**지역은 계산에 필요한 범위까지만 답하세요.** 지역별 기준을 확인해야 할 때는 시·군·구 등 필요한 정보를 추가로 물을 수 있습니다. 계약서 전체나 정확한 주소를 먼저 제출할 필요는 없습니다.

**예시나 비교만 필요하면 가상 숫자를 써도 됩니다.** 실제 금액과 다른 조건이라는 점을 알려 주면 AI가 가정 계산으로 설명할 수 있습니다.

## 대화와 입력 파일이 남을 수 있습니다

**AI가 만든 계산 입력은 대화 기록이나 로컬 파일에 남을 수 있습니다.** 플러그인에는 별도 데이터베이스가 없지만, 호스트 도구의 대화 기록과 작업 폴더는 해당 도구가 관리합니다.

**파일 삭제를 원하면 계산용 입력 파일의 위치와 삭제 가능 여부를 AI에 확인하세요.** 실제로 어떤 파일이 만들어졌는지 확인한 뒤 계산용 임시 파일만 정리해야 합니다. 플러그인이 호스트 서비스의 대화 기록까지 자동으로 지우지는 않습니다.

## 공개 질문에는 가상 정보를 사용하세요

**GitHub에 올린 이슈와 댓글은 공개될 수 있습니다.** 오류를 신고할 때는 실제 답변이나 계약서 대신 같은 문제를 재현하는 가상 금액과 조건을 적어 주세요.

**공개 자료에는 이름·주소·식별번호·인증 정보를 넣지 마세요.** 전체 대화 로그, 스크린샷, 입력 파일은 개인 정보가 섞여 있는지 먼저 확인해야 합니다. 필요한 오류 신고 항목은 [기여 안내](../CONTRIBUTING.md)에 있습니다.
