# 처음 시작하기

**설치는 한 번만 하고, 계산은 대화로 요청하면 됩니다.** 이 안내는 명령어에 익숙하지 않은 사람을 기준으로 설명합니다. 설치가 끝나면 계산기 목록을 외울 필요가 없습니다.

## 사용할 환경을 확인하세요

**이 플러그인은 로컬 명령을 실행할 수 있는 Codex 또는 Claude Code에서 사용합니다.** 일반 Claude 웹·앱 대화에 파일을 첨부하는 방식으로는 계산 프로그램이 포함된 플러그인을 설치할 수 없습니다.

**Node.js 22 이상이 계산을 실행합니다.** Node.js는 이 플러그인에 들어 있는 계산 프로그램을 실행하는 도구입니다. 설치된 버전을 직접 확인하기 어렵다면 아래 설치 요청을 AI에 보내 확인을 맡기세요.

**Codex나 Claude Code의 이용 조건은 각 서비스에서 확인하세요.** 이 저장소가 AI 계정이나 유료 서비스 이용 권한을 제공하지는 않습니다.

## AI에 설치를 요청하세요

**아래 문장을 현재 사용 중인 Codex 또는 Claude Code에 붙여 넣으세요.** AI가 실행 환경과 Node.js 버전을 확인한 뒤, 해당 제품의 플러그인 설치 절차를 진행하도록 요청하는 문장입니다.

```text
minsooparkk/budongsan-skills GitHub 저장소의 플러그인을 설치해 줘.
플러그인 설치와 로컬 계산 프로그램 실행이 가능한 환경인지 먼저 확인해 줘.
Node.js 22 이상이 설치되어 있는지도 확인해 줘.
필요한 설치를 진행하고, 끝나면 새 대화를 시작하는 방법을 알려 줘.
```

**새 대화에서 첫 계산을 요청하세요.** 설치 직후 진행 중이던 대화에는 새 스킬이 반영되지 않을 수 있습니다.

```text
budongsan-skills로 84제곱미터가 몇 평인지 계산해 줘.
```

**25.41평이라는 결과가 나오면 첫 계산을 확인할 수 있습니다.** 이 예시는 입력한 면적의 단위만 바꾸는 계산이므로, 세금이나 대출 정보를 준비할 필요가 없습니다.

## 원하는 계산을 말하세요

**상황을 설명하면 AI가 관련 스킬을 찾습니다.** “부모님에게 돈을 받을 예정인데 세금이 궁금해”처럼 말해도 됩니다. 여러 계산이 가능하면 먼저 무엇을 계산할지 정리합니다.

**알고 있는 정보는 한 번에 알려 줘도 됩니다.** AI는 이미 답한 내용을 활용하고, 부족한 정보를 이어서 확인합니다.

```text
대출 이자를 계산해 줘.
1억원을 연 4%로 1년 동안 빌릴 예정이고,
원금은 마지막에 한 번에 갚을 거야.
선택 질문은 기본 전제를 적용하고, 어떤 전제인지 결과에 써 줘.
```

**계산기 이름을 알고 있다면 직접 호출할 수 있습니다.** Codex에서는 `$chwideuk`처럼 스킬 이름을 입력하거나 스킬 선택 화면을 이용하고, Claude Code에서는 `/budongsan-skills:chwideuk`처럼 입력합니다.

| 원하는 계산 | Codex에서 요청 | Claude Code에서 호출 |
| --- | --- | --- |
| 취득세 | `$chwideuk` | `/budongsan-skills:chwideuk` |
| 대출 이자 | `$daechul-ija` | `/budongsan-skills:daechul-ija` |
| 면적 환산 | `$pyeongsu` | `/budongsan-skills:pyeongsu` |

**전체 이름은 [계산기 안내](calculators.md)에서 찾을 수 있습니다.** 목록에는 각 스킬의 용도와 필수 질문·선택 전제가 함께 나옵니다.

## 필수 질문부터 답하세요

**필수 질문에는 실제 사실이나 비교하고 싶은 조건을 답하세요.** 대출금액이나 금리처럼 계산의 바탕이 되는 수치는 건너뛰면 내 상황에 맞는 결과를 낼 수 없습니다. “금리는 아직 몰라”라고 말하면 필요한 자료를 안내하거나, 사용자가 정한 가정으로 비교할 수 있는지 확인합니다.

**선택 질문은 “기본값으로 해 줘”라고 답해도 됩니다.** AI는 적용할 전제를 설명하고, 그 전제를 결과에도 표시합니다. 선택 질문을 건너뛰었다는 이유만으로 사용자의 실제 사정을 확인한 것으로 취급하지 않습니다.

**모르는 세금 용어는 설명을 요청하세요.** 예를 들어 “주택 수에 무엇을 포함해야 하는지 쉽게 설명해 줘”라고 말할 수 있습니다. 답변에 따라 필수 질문이 추가될 수 있습니다.

**금액에는 단위를 붙이면 혼동을 줄일 수 있습니다.** “5억 2천만원”, “월 80만원”, “연 4%”, “전용 84㎡”처럼 말하세요. “500”처럼 단위가 없는 수치는 AI가 다시 확인해야 합니다.

## 결과와 전제를 함께 확인하세요

**결과에서 먼저 볼 것은 예상 금액과 적용한 전제입니다.** 사용자가 답한 금액이 맞는지, 건너뛴 선택 질문이 어떤 값으로 처리됐는지 확인하세요. 세금 계산이라면 적용 시점과 확인이 필요한 요건도 함께 살펴보세요.

**조건은 대화로 바꿔 다시 계산할 수 있습니다.** “금리만 연 5%로 바꿔 줘”, “감면 없이 계산해 줘”, “두 결과의 차이를 보여 줘”처럼 말하면 됩니다.

**계산 범위 밖이라는 안내가 나오면 필요한 확인 사항을 보세요.** 양도세의 특수한 거래처럼 동봉된 계산식이 다루지 못하는 조건은 숫자를 확정할 수 없습니다. AI가 알려 주는 추가 정보와 관련 자료를 바탕으로 다음 확인을 진행하세요.

## 직접 설치하려면 아래 명령을 쓰세요

**Codex CLI 설치 명령은 터미널에서 실행합니다.** 터미널은 컴퓨터에 명령을 입력하는 창입니다.

```sh
codex plugin marketplace add minsooparkk/budongsan-skills
codex plugin add budongsan-skills@budongsan-skills
```

**Claude Code 설치 명령은 Claude Code 대화창에 입력합니다.** 첫 명령은 플러그인 목록을 등록하고, 두 번째 명령은 그 목록에서 이 플러그인을 설치합니다.

```text
/plugin marketplace add minsooparkk/budongsan-skills
/plugin install budongsan-skills@budongsan-skills
```

**공식 설치 안내에서 제품별 지원 범위를 확인할 수 있습니다.** [Codex 플러그인 문서](https://developers.openai.com/plugins/build/plugins), [Claude Code 플러그인 문서](https://code.claude.com/docs/en/plugins), [Claude Code 마켓플레이스 문서](https://code.claude.com/docs/en/plugin-marketplaces)를 참고하세요.

## 문제가 생기면 증상을 그대로 알려 주세요

**스킬이 보이지 않으면 설치 여부와 새 세션 반영을 먼저 확인하세요.** “budongsan-skills가 설치됐는지 확인하고, 스킬이 안 보이는 이유를 찾아 줘”라고 AI에 요청하면 됩니다.

**계산 프로그램이 실행되지 않으면 Node.js 버전을 확인하세요.** “Node.js가 22 이상인지 확인하고, 이 플러그인의 계산 프로그램을 실행해 줘”라고 요청하세요.

**오류를 공개할 때는 가상 숫자로 바꿔 주세요.** 이름, 계좌번호, 주민등록번호, 실제 계약서나 전체 대화는 GitHub에 올리지 마세요. 필요한 정보는 [기여 안내](../CONTRIBUTING.md)와 [개인정보 안내](privacy.md)에 있습니다.
