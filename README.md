# 부동산 계산을 대화로, budongsan-skills

**부동산 세금과 비용은 평소 말하듯 질문해서 계산할 수 있습니다.** `budongsan-skills`는 budongsanbaksa의 계산기를 바탕으로 만든 58개 스킬 모음입니다. 스킬은 AI가 특정 일을 처리하도록 돕는 사용 설명서이며, 이 플러그인은 계산기별 스킬과 실제 계산 프로그램을 한 번에 제공합니다.

**세법이나 계산식을 몰라도 시작할 수 있습니다.** “집을 살 때 세금이 얼마나 나와?”라고 말하면 AI가 알맞은 계산기를 고르고, 필요한 정보를 묻고, 답변을 계산 프로그램에 넣습니다. 결과에는 예상 금액과 적용한 전제가 함께 나옵니다.

**결과는 입력과 동봉된 계산식에 따른 예상치입니다.** 계산식 스냅샷 날짜는 2026-09-07이며, 이 날짜가 모든 최신 법령을 검증했다는 뜻은 아닙니다. 양도세·보유세에는 계산 가능한 상황의 제한이 있으며, 개편안 계산은 가정 시뮬레이션으로 구분합니다.

## 이렇게 시작하세요

**아래 문장을 Codex 또는 Claude Code에 붙여 넣으면 설치부터 요청할 수 있습니다.** 로컬 명령을 실행할 수 있는 Codex 환경이나 Claude Code가 필요하며, 계산을 실행하는 프로그램인 Node.js 22 이상도 필요합니다. 설치를 맡은 AI에게 필요한 프로그램을 먼저 확인하도록 요청하세요.

```text
GitHub의 minsooparkk/budongsan-skills 플러그인을 설치해 줘.
지금 환경에서 플러그인 설치와 로컬 명령 실행이 가능한지 먼저 확인하고,
Node.js가 22 이상인지도 확인해 줘.
설치가 끝나면 새 대화를 시작해야 하는지 알려 줘.
```

**설치 후에는 계산하고 싶은 일을 그대로 말하면 됩니다.** 계산기 이름이 떠오르지 않아도 괜찮습니다.

```text
budongsan-skills로 집 살 때 드는 취득세를 계산해 줘.
필수 질문부터 물어보고, 선택 질문은 기본 전제를 알려 줘.
선택 질문은 건너뛸 수 있게 해 줘.
```

**자세한 설치 방법은 [처음 시작하기](docs/quick-start.md)에 있습니다.** 일반 Claude 웹·앱 대화에 파일을 첨부하는 방식은 실행형 플러그인 설치에 해당하지 않습니다.

## 필요한 질문만 답하세요

**필수 질문은 내 상황을 계산하는 데 꼭 필요한 질문입니다.** 금액, 거래 종류, 주택 수처럼 결과를 크게 바꾸는 사실은 AI가 임의로 정하지 않습니다. 답을 모르면 어떤 정보를 확인해야 하는지 안내합니다.

**선택 질문은 건너뛰고 정해진 전제로 계산할 수 있습니다.** 예를 들어 대출 계산에서 별도의 거치기간을 답하지 않으면 “거치기간 없음”으로 계산할 수 있습니다. 거치기간은 원금을 갚지 않고 이자만 내는 기간을 뜻합니다.

| 구분 | 예시 | 답하지 않으면 |
| --- | --- | --- |
| 필수 질문 | “대출받을 금액은 얼마인가요?” | 금액을 다시 확인합니다. |
| 필수 질문 | “대출금리는 연 몇 %인가요?” | 적용할 금리를 확인합니다. |
| 선택 질문 | “원금을 갚지 않고 이자만 내는 기간이 있나요?” | 해당 계산기의 기본 전제를 적용하고 결과에 표시합니다. |

**기본 전제는 사용자가 확인한 사실과 구분해서 보여 줍니다.** “선택 질문은 건너뛸게”라고 답해도 되며, 나중에 “거치기간을 1년으로 바꿔 줘”라고 말하면 조건을 바꿔 다시 계산할 수 있습니다. 필수·선택 구분과 기본 전제는 계산기마다 다릅니다.

## 이런 일을 계산할 수 있습니다

**계산기는 생활 속 상황으로 골라도 됩니다.** 전체 58개 목록과 각 계산기의 필수 질문·선택 전제는 [계산기 안내](docs/calculators.md)에서 확인할 수 있습니다.

| 원하는 일 | 이렇게 말해 보세요 | 대표 스킬 |
| --- | --- | --- |
| 집을 살 때 드는 세금 확인 | “아파트 취득세를 계산해 줘.” | `chwideuk` |
| 집을 가진 동안 내는 세금 확인 | “재산세를 계산해 줘.” | `jaesan`, `boyuse` |
| 집을 팔 때 생기는 세금 확인 | “이 조건으로 양도세를 계산할 수 있는지 확인해 줘.” | `yangdo` |
| 가족에게 재산을 줄 때 세금 확인 | “자녀에게 돈을 주면 증여세가 얼마야?” | `jeungyeo`, `sangsok` |
| 부동산 거래 비용 확인 | “복비와 등기비용을 계산해 줘.” | `junggae`, `deunggi` |
| 대출 부담 비교 | “대출 이자와 매달 갚을 돈을 계산해 줘.” | `daechul-ija`, `daehwan` |
| 전세·월세 비교 | “전세와 월세 중 어느 쪽 비용이 적어?” | `jeonse-vs-wolse`, `jeonwolse` |
| 임대수익과 경매 비용 확인 | “월세 수익률을 계산해 줘.” | `imdae-suik`, `jeokjeong-ipchal` |
| 면적과 가격 환산 | “전용 84㎡가 몇 평인지 알려 줘.” | `pyeongsu`, `danwi-gagyeok` |

**세금 이름은 돈이 오가는 상황과 연결해 설명합니다.** 취득세는 부동산을 취득할 때, 재산세는 보유할 때, 양도소득세는 팔아서 이익이 생겼을 때 살펴보는 세금입니다. 증여세는 살아 있는 사람에게 재산을 받을 때, 상속세는 사망한 사람이 남긴 재산을 물려받을 때 살펴봅니다. 실제 세금 발생 여부와 금액은 개별 조건에 따라 달라집니다.

## 결과는 이렇게 읽으세요

**예상 금액과 계산 전제를 함께 확인하면 결과를 내 상황에 맞게 사용할 수 있습니다.** AI는 먼저 결론을 말하고, 사용자가 답한 정보와 선택 질문에서 적용한 기본 전제, 계산 과정, 추가로 확인할 조건을 설명합니다.

> **84㎡는 25.41평입니다.** 입력한 면적 84㎡를 그대로 환산했으며, 1평은 400/121㎡로 계산했습니다. 전용면적을 공급면적으로 바꾸는 계산은 아닙니다.

**구체적인 대화는 [사용 예시](docs/examples.md)에서 볼 수 있습니다.** 질문을 일부 건너뛰거나 답을 모를 때의 흐름도 함께 설명합니다.

## 계산 범위를 확인하세요

**세금 계산에는 기준 시점과 적용 조건 확인이 필요합니다.** 거래일에 시행되는 법령, 지역 기준, 감면 요건에 따라 결과가 달라질 수 있습니다. “감면”은 일정한 조건을 갖췄을 때 세금을 줄여 주는 혜택이며, 요건을 확인하지 않은 혜택은 자동으로 적용하지 않습니다.

**양도세와 보유세는 지원하는 조건 안에서만 계산합니다.** 전체 신고서 작성이나 모든 예외 판정을 대신하지 않으며, 범위를 벗어난 조건은 추가 확인이 필요하다고 안내합니다. 계산기별 범위는 [계산기 안내](docs/calculators.md), 계산식의 출처와 검증 범위는 [출처 안내](docs/source-provenance.md)에 있습니다.

**개편안은 법이 바뀌었다고 가정한 비교 결과입니다.** `yangdo-sim` 등에서 나오는 미래 연도 결과를 확정된 세금으로 읽지 마세요. 현행법을 적용한 결과인지, 별도의 가정을 적용한 결과인지 구분해서 표시합니다.

**대출·보증보험·평가·경매 결과도 계산상의 예상치입니다.** 대출 승인이나 보험 가입, 감정평가액, 실제 배당 순위를 확정하지 않습니다. 금융회사 약정이나 물건별 권리관계처럼 계산기 밖의 조건은 별도로 확인해야 합니다.

## 내 정보는 이렇게 처리됩니다

**플러그인에는 별도 계산 서버나 자체 이용 추적 기능이 없습니다.** 계산 프로그램은 로컬에서 실행되며, 플러그인 자체가 답변을 budongsanbaksa 서버로 보내지 않습니다. AI에 입력한 대화는 이용 중인 Codex·Claude 서비스의 처리 정책을 따릅니다.

**실명이나 주민등록번호 없이 계산할 수 있습니다.** 금액과 관계, 필요한 범위의 지역 정보만 답하세요. 자세한 내용은 [개인정보 안내](docs/privacy.md)에 있습니다.

## 직접 설치하거나 기여할 수 있습니다

**Codex CLI에서는 다음 두 명령으로 설치합니다.** 설치 후 새 세션에서 스킬을 사용하세요.

```sh
codex plugin marketplace add minsooparkk/budongsan-skills
codex plugin add budongsan-skills@budongsan-skills
```

**Claude Code에서는 다음 두 명령을 대화창에 입력합니다.** 설치 후 새 세션에서 `/budongsan-skills:chwideuk`처럼 실행할 수 있습니다.

```text
/plugin marketplace add minsooparkk/budongsan-skills
/plugin install budongsan-skills@budongsan-skills
```

**설치 구조는 각 제품의 공식 플러그인 방식을 따릅니다.** 환경별 안내는 [Codex 공식 문서](https://developers.openai.com/plugins/build/plugins), [Claude Code 플러그인 문서](https://code.claude.com/docs/en/plugins), [Claude Code 마켓플레이스 문서](https://code.claude.com/docs/en/plugin-marketplaces)에서 확인할 수 있습니다.

**기여는 쉬운 설명의 개선부터 시작할 수 있습니다.** 계산 오류나 이해하기 어려운 질문은 개인 정보를 지운 가상 예시와 함께 알려 주세요. 개발과 검증 방법은 [기여 안내](CONTRIBUTING.md), 법령 확인에 사용하는 자료는 [법령 출처](docs/legal-sources.md)에 정리되어 있습니다.
